# 提示词信息归属与 DRY

编写或联合优化 Bot、Task、Map/node 及关联资料时，用本文判断信息归属、消除重复并核对执行侧可达性。本文维护跨对象的整理方法；业务步骤留在对应 Task，字段格式与运行协议仍以产品文档为准。

## 按消费者归位

先问：谁需要这条信息、何时需要、需要它作什么决定？再选择权威位置。

| 信息 | 权威位置 | 消费者与用途 |
| --- | --- | --- |
| 适用场景、能力边界、输入和成果摘要 | Bot 四字段 | chief、规划者等发现、选用和组合能力 |
| 流程用途 | Map.description | 浏览和选择 Map 的人或 Agent |
| 整图输入要求、公开成果及格式入口 | Map 输入输出规则 | 调用者、父图转换者、输入准备和交接管理者 |
| 独立使用也必需的稳定职责与完成条件 | Task／script／Map 实现及其引用资料 | 实际执行者完成工作 |
| 本次目标、范围、材料用途和额外约束 | 用户实际输入、node.input | 执行者落实本次委托 |
| 本流程特有的材料格式和阶段标准 | Map 同名目录下的业务文档 | 生成或消费对应材料的执行者 |
| 来源、依赖、位置及执行策略 | 结构化配置 | 系统解析接线与执行条件 |
| 身份、批准、报告、交接及完成 | 公共角色说明与工具指引 | 管理者和节点执行通用协议 |
| 多个流程共用的整理方法或业务标准 | 共享 Skill／文档 | 适用消费者按条件读取 |

实现完整后，node.input 只补本次差异和流程特有的读取条件；没有差异可以为空。Map.description 只描述用途，业务标准通过执行侧入口提供。管理者按公共协议编排和交接，节点承担自身业务执行与检查。

具体字段职责与接口查询 [scheduler](scheduler.md#定义职责与唯一格式)；Bot 四字段的表达格式查询[四字段编写与表达优化](business-materials.md#四字段编写与表达优化)。本文不复制 schema、HTTP 请求或角色操作步骤。

## 一项规则，一个权威

以一个可独立改变的含义为整理单位，而不是按原段落整体迁移。

- 详细规则只维护一次；消费者通过有触发条件的指针读取。Task 保留步骤顺序、调用条件和完成标准，操作细则归对应参考。
- 能力摘要和执行规则服务不同决定，可以概述同一能力；摘要只保留影响选用与组合的信息，不复制内部步骤。
- 文件格式由实际接口或唯一材料契约定义。接口指向外部契约时，说明材料含义和读取入口，不再复述整套格式。
- 需求交接保存已经确认的决定及必要上下文，配置和源码从真实目标读取；确需历史快照时明确其用途，不默认复制完整对象。
- 环境中的路径、字段和命令能直接查得时，优先指向其权威。文档记录约定、原因和查阅条件，避免另存一份易过期清单。

精简先判断一条信息是否改变行为；无作用的整句删除。仍有作用的信息归位后再删旧正文，不以“其他地方可能有”作为承接证据。

## 指针与信息层级

步骤直接说明本阶段做什么，以及何时完成；只在特定分支需要的细则放到引用资料中。指针写明触发条件、文档位置和所需章节，例如“修改 Task.prompt 前，读取……”。

同一条件只留一个入口；独立调用与流程调用都需要的指针放在 Task，本流程专用材料的指针放在 node.input。定义、约束和例外放在同一主题下，避免消费者只读到其中一部分。

共享资料放在共享位置；流程资料与 Map 就近维护。拆分以真实的消费者或分支为界，不为每条规则新建文档。

完成条件须能区分完成、受阻与部分效果，覆盖本阶段承诺的全部结果。优先正面描述目标行为，必要的权限和安全边界保留明确限制。清晰优先于一味缩短。

## 核对实际可达性

迁移或删除每项执行必需信息前，逐项核实：

1. 新权威包含完整有效内容，旧位置已改为必要摘要或读取指针。
2. 真正的消费者会取得这个指针，触发条件覆盖需要该信息的分支。
3. 路径、词典变量、工作目录和文件绑定能在该调用场景下解析，材料可读。
4. 独立 Task、普通节点、嵌套 Map 等实际涉及的调用方式均有入口。

Bot 文案不自动注入执行 Chat，Map.description 也不是管理者或节点的指令入口。字段存在、文档可打开、依赖边成立，都不证明某个执行者实际收到信息。上下文传递依赖真实机制，缺少传值能力时先暴露缺口，不以提示词声称已经继承。

共享对象修改前列出其他消费者和受影响的调用方式，取得相应修改范围；不据此自动扩大为迁移全部消费者。

## 审阅完成标准

- 每项有效业务要求都有明确权威与实际消费者，原含义和授权边界保持，业务修订另有确认。
- 摘要足以选用，实现足以独立执行，本次差异与运行接线各归其位。
- 重复细则已消除，必要指针有明确触发条件，读到步骤时能找到对应规则。
- 已执行、已保存、已检查与未验证分别陈述；静态可达性核对不冒充模型遵从或业务验收。
