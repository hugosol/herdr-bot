# 集成边界

## 发起 Chat 不等于任务完成

Bot 的固定 prompt 与本次 input 属于用户输入，不是 system-role 指示。选择 Skill 时按目标 agent 的原生语法合成为一次提交，不先运行无任务的 Skill 轮次再补发任务。

Herdr 确认 agent 可交互且初始指示提交获确认，才表示发起成功；这不证明模型完成任务、Skill 已加载或执行成功。终端信任提示、资源加载、账号权限及模型可用性仍由目标 agent 决定。

失败保留已经创建的 Tab／Pane／agent，不自动删除、重建或重发初始输入；超时不能证明外部操作未发生。只有尚未创建外部对象的 Workspace 查找失败允许在原弹窗重新提交。

## 扩展与默认配置

Bot 保存稳定的选项标识，不保存入口映射副本。`meta-data/bot-options.toml` 是 agent、模型、思考级别及扩展适用关系的来源；变更后下次操作重新读取。失效选择需要显式修正并保存，不能悄悄替换为默认值。

启动时关闭扩展自动发现，再显式加载固定项与 Bot 所选可选项。Herdr 官方状态／原生身份扩展因此必须是固定项；它不代替可选的 connect-bot。入口可读检查不执行扩展，也不证明实际加载成功。

## 原生对话与历史

每次发起 Chat 新建 Herdr Tab 和 agent 控制对象，但不保证新建原生对话。herdr-bot 不覆盖原生会话目录，不改变 agent 的 autoResume 等有效设置，也不搬动原生主文件或附属记录；同一目录可能续接已有对话。

历史按完整原生会话身份收录，不按名称、cwd 或最近修改的文件猜测身份。发起成功后，历史身份收录独立进行，最多等待 30 秒；失败仅给出服务端诊断，不把已成功发起的 Chat 改成失败，也不重发初始输入。

connect-bot 是独立的接入机制：未接入的 Chat 也可以存在并被收录到历史；接入后才有当前会话登记。删除当前登记不删除历史或原生对话。

## 历史 Chat Resume

历史列表的 **Resume** 与 `POST /api/chats/resume`（仅提交 `sessionId`）使用同一条恢复路径。先查询 Herdr 的原生对话身份；找到已有目标只做 Herdr 内部导航，查询失败不会当作无匹配。缺少／未知／不支持的 agent 类型会明确拒绝，不按文件形状猜测类型。

同一 herdr-bot 实例按所选历史 Chat 持有执行资格，覆盖查找、创建、启动、确认与聚焦，不依赖单页按钮状态。同一 Chat 已在执行时，其他页面或独立请求立即收到 HTTP `409`／`resume-in-progress`；本次未执行、不会排队，也不会在首个操作完成后自动启动。浏览器呈现后端忙碌结果，不乐观宣称成功；定位、恢复完成或明确失败后释放资格，用户新发起的操作仍从查找开始。已接受操作不因原请求连接关闭而提前释放资格；不同 Chat 互不阻塞。该边界仅在当前服务实例内，不是多实例分布式锁，也不改变会话登记、历史身份或原 Workspace 的生命周期。

成功查询且没有匹配时，Pi 在历史记录的绝对 cwd 中创建新 Tab 并加载原生 session。缺少原 Workspace 信息的旧记录使用 `[herdr] workspace_name` 精确匹配的唯一默认 Workspace，并在结果中说明回退；默认 Workspace 缺失、重名或查询失败都不创建替代位置。Resume 不改写历史记录的原 Workspace 信息。

恢复优先使用可读取且原生 ID 一致的 `sessionFile`，不可用时只使用所选原生 ID 作为 `--session` 目标。若历史身份本身是已不可读的路径而不能核实 ID，则明确失败，不扫描最近文件或改用空白对话。使用 Herdr 当前配置的 `pi` 启动命令，关闭扩展自动发现，并显式加载当前 Bot 选项目录中 Pi 的固定集成；不读取任何 Bot 来应用模型、思考级别、Skill、可选扩展、固定初始指示或新输入。

启动命令返回不等于恢复成功：确认新进程报告同一原生身份和实际 cwd 后，还需确认聚焦正确的 Workspace／Tab／Pane，才返回 `restored`。类型、工作目录、必要集成、启动、身份或聚焦失败均有可见结果；已经创建的目标保留供检查，不自动另开、删除或重发输入。页面／HTTP 成功只表示 Herdr 内部导航，不保证 Windows 窗口已置前，也不承诺 agent 自身的模型恢复规则。Pi 使用 session 加载且项目不提交输入；真实历史内容及无主动任务活动由专用 H-Pi 验收确认，受控调用记录不能代替该确认。

## 验证边界

受控 Herdr 可以证明调用参数与失败处理，不能证明真实 agent 加载了扩展。桌面浏览器窄屏仿真不能替代真实手机的触摸、软键盘和输入法验证。历史原始证据保留在 [`evidence/`](evidence/)，不作为当前构建已经重新通过的证明。
