# 接受尚未落盘的 omp / pi 启动身份

2026-10-29 补充：pi 同样先分配会话 ID 和路径，首次用户或助手消息出现前不创建原生文件。下述受限启动身份规则同时适用于官方 `herdr:pi` 引用及 pi 的相同时间戳与 UUID 文件名约定；pi 不接受 omp 专属的标题元数据行。此扩展也覆盖可信启动历史对应的未落盘当前 Chat 定位，但不改变实际新进程恢复时的文件及原身份确认要求。

omp 在新会话中先分配原生 ID 和文件路径，默认在产生 assistant 消息后才创建会话文件。Herdr 官方集成优先上报路径，而 workflow 要求先保存真实身份关联再提交初始指示，因此不能把文件尚未落盘等同于会话不存在。只修改 herdr-bot，不修改 Herdr 集成、不预先发送任务、不伪造原生文件：对本次新启动的 omp，仅当官方 `herdr:omp` 引用为绝对路径、文件打开失败为 NotFound、文件名符合 omp 的时间戳与 UUID 约定且有实际进程 cwd 时，接受路径中的原生 ID。

这是对 Herdr 引用和 omp 命名约定的显式信任，不等同于文件头验证。文件存在时仍以文件头为准；权限、损坏、非标准路径及 omp / pi 之外的 agent 不使用此例外。取得身份后照常先保存 Run 关联和历史，再提交初始指示；历史保留预期文件路径及仅由可信发起流程写入的 `startupIdentityPath`，不承诺文件已落盘或当前可恢复。

Resume 仅对保存的原生 ID、`startupIdentityPath` 与当前官方路径引用完全吻合的未落盘候选允许定位，不向任意历史或其他候选推广。实际读取已保存身份对应的文件时若发现 ID 冲突，明确拒绝，不跳过冲突后启动另一 Chat，也不覆盖原身份。新进程恢复仍须确认原身份，不因路径符合命名约定就声称恢复成功。

不新增后台落盘轮询、补关联、自动改绑或原生文件修复，不改变现有失败 Run。没有选择延长等待（无法消除首次输入前不落盘的依赖环）或先提交任务（会让尚未关联的 Chat 开始执行）。此决定依赖 omp 的原生文件名约定；约定变化应明确拒绝，而非猜测。

## 2026-11-20：Task 发起的原生启动上报

TUI 的 `herdr:omp` / `herdr:pi` 官方路径引用仍按上述规则取证。由 Task 发起时，TUI 与 App 另从 connect-bot 接收原生启动身份与 framework 输入就绪事件。上报仍受 [ADR 0004](0004-session-write-boundary-same-host.md) 的同机来源限制；启动关联值仅用于关联，既不是远程认证，也不是原生会话、Pane 或终端 ID。

后端核对本次启动的关联值、agent 类型、原生会话 ID、cwd、活跃进程及实际放置。TUI 用所选 Pane 的进程和目标位置核对；如果官方原生引用已出现，必须与上报一致。App 用 App 布局和所选 core 的终端归属、启动命令与活跃进程核对；原生 ID 和可选的已分配路径来自此次上报的 agent，不是把终端地址转为会话 ID，也不从任意未落盘文件名推断。存在原生文件时核对实际头部身份，未落盘不伪造文件，也不因此获得官方引用的 `startupIdentityPath` 凭据。独立确认 TUI Pane 与进程后，宿主本身提供的无效官方引用或与发起目录冲突的官方 cwd 直接使本次发起失败，保留具体诊断；未获验证或与有效官方身份不符的上报只拒绝该事件，不阻止正确上报。

同一会话的身份与 ready 均确认后，后端才向所选终端提交初始指示；不会提前预填业务消息。普通会话登记、在线状态、idle、等待用户输入及关机监听均不受这些启动事件驱动。页面只读取后端的初始化与提交结果。已失效的 owner 或目标不能继续授权提交。

## 2026-11-20：历史 Chat 的 B1 降级与未确认结果

需要新进程的 Resume 使用来源 Task 当前的会话环境、Suite 与原执行角色适用的固定扩展，不重放模型覆盖、初始 Skill 或初始消息。真正无来源、来源已删除、无法读取会话环境及 Suite 配置错误均只使用 agent 原生默认发现；不显式追加 Task/Suite 资源、不强制加入 connect-bot，也不改变已保存的 `sourceTaskId`。默认资源范围可能与原 Suite 不同。新 Chat 仍按发起规则校验，不使用此降级。

有可靠原生证据时仍核对 ID、已有文件证据与 agent 类型。无证据时，只有启动请求与对应目标的 Herdr 内部定位都已确认，才能报告「已请求恢复并定位，原生身份未确认」；启动超时不能冒报已定位。启动参数、历史文件名和终端位置都不证明已加载原对话。已知身份冲突、历史读取错误或明确启动／定位失败仍然失败；没有自动改绑、再次启动或输入重放。对应 Resume 按钮保留实际选择的降级原因、策略和最终结果。
