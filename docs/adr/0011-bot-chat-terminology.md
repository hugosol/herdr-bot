# Bot 表示预设，Chat 表示实际对话

- 状态：accepted
- 日期：2026-10-23

## 决策

**Bot** 是 `bot` 入口管理的可复用预设；**Chat** 是实际 agent 对话。从 zone 选择 Bot 的动作称为“发起 Chat”。不再将 Bot 用作对话实例名称，也不再为预设另设 template 概念。

这是一次内部契约硬切换：Bot 管理使用 `/api/bots`，Chat 发起、预览与生命周期使用 `/api/chats`；字段、代码和文件名同步使用 Bot／Chat 含义，配置使用 `[bots]`，默认存储为 `.data/bots.json`。Chat 命名规则使用 `{zone.name}`、`{bot.name}`、`{agent}`、`{chat.id}`。已有 Bot 标识视为不透明身份，不因更名重新生成。

旧格式通过显式的一次性迁移切换，不在运行时保留旧路由、字段或配置别名。connect-bot 的会话接入契约、zone 登记、历史会话及 agent 原生文件不改变。

## 原因与代价

旧定义将 Bot 预设和由它发起的对话分成“模板／Bot”，与主界面 `bot` 和 `chat` 两个入口的实际含义相反，导致 `botId` 等标识同时承担错误的领域含义。只改文案会把歧义留在接口和存储中；同时维护旧名别名则产生两套契约。

除 connect-bot 接入接口外，这些接口目前没有外部调用方，因此趁当前完成硬切换。代价是旧页面、配置和工具必须一起升级；停止旧服务后运行迁移，再构建并启动新版。不能让旧进程继续写旧格式数据。

当前文档统一新术语。历史 ADR 保留决策事实，原始证据及 `.scratch/` 票据不改写；README 的重复历史与交付流水账删除，不另建归档副本。
