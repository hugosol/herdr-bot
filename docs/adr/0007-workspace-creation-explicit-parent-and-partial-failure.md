# workspace 创建使用显式父目录且失败不回滚目录

> 术语更新（2026-10-21）：本文的 workspace 现称 zone；原因与硬切换范围见 [ADR 0009](./0009-rename-workspace-to-zone-for-herdr.md)。正文保留原文。

- 状态：accepted
- 日期：2026-10-21

“新增 workspace”只接受一个直接子目录名称，父目录必须由服务端配置显式提供（随附配置为
`E:\Developer\bot-playground`），代码中没有静默兜底。未配置时服务只禁用“新增”，登记已有目录与浏览仍正常；
配置父目录缺失时请求明确失败，也不自动创建父目录。选择显式配置而不是隐藏默认值，是为了让服务端写入位置
可见、可审查，避免在用户没有确认的位置创建目录。

创建按“目录 → `git init` → 持久化登记”执行，三者不是可回滚事务。任一步失败都保留已经产生的目录，并在
反馈中说明失败阶段与完整路径；若只有登记失败，用户可用既有“登记”入口登记该目录。备选方案是失败时递归删除
新目录，但目录在失败后可能已被其他程序写入，自动删除风险更高，因此拒绝。成功不生成 README、首次提交或远程
仓库；同名目录已存在时拒绝，不覆盖、不复用。
