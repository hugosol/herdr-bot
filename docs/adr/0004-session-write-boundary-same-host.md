# 会话写入只接受同机来源，读取对局域网开放，不引入 token

- 状态：accepted
- 日期：2026-10-01

> 术语注记（2026-10-21）：项目已更名 **herdr-bot**，mDNS 主机名现为 `herdr-bot.local`；原因与硬切换范围见 [ADR 0010](./0010-rename-project-to-herdr-bot.md)。旧端点、旧扩展配置和 v1 假设仅为决策语境。现行同机判定见 [`backend/src/sessions/mod.rs`](../../backend/src/sessions/mod.rs) 的 `is_local_source`。

`POST /api/sessions/events`（`register` / `heartbeat` / `state` / `unregister` 四种事件）只接受**同机来源**
的请求：TCP 对端 IP 是回环地址（`ip.is_loopback()` 覆盖 `127.0.0.0/8` 与 `::1`），或属于本机网卡地址集合
——后者在**每次写入**时用 `if-addrs` 现枚举，DHCP 换址后旧地址不会残留成误放行的口子；枚举失败时按「不是
本机」拒绝，边界默认关闭。其余来源一律 `403 forbidden`，且拒绝发生在建行或改动任何会话之前。读取侧相反：
页面与 SSE 长连接 `GET /api/sessions/events` 对局域网**全开**，**不引入 token**。

默认端点沿用扩展配置里的 `http://omp-bot.local:8787`（`extensions/connect-bot/config.json` 单键
`endpoint`）：同机扩展经 mDNS 主机名连进来时，服务端看到的对端地址是本机网卡地址，仍在接受范围内，因此
ADR-0001 的「mDNS 主机名为主入口」不受影响，扩展不必改配置。**v1 不支持非同机扩展**（跨机需要认证与实例
身份，属新 effort）。

这是 ADR 0002「仅可信局域网、无认证」边界内的一次收紧，防止局域网其他设备伪造会话登记。服务端必须取得实际 TCP 对端地址。**来源校验不是认证**，同机任意进程仍能写入。

## 备选与代价

- **仅回环**会拒绝同机经 mDNS 连接时使用本机网卡地址的请求，与以 mDNS 主机名为主入口的选择冲突。
- **局域网全开**省去来源检查，但局域网任意设备都能伪造会话登记。
- **轻量 token**需要分发与配置，超出当时的单机范围，不为跨机客户端或多用户提前引入。

## v1 单实例假设

决策当时假定同一台机器只有一个实例，会话协议不带实例身份。指向另一个实例与原实例重启无法从协议区分；新实例对未知会话的非 `register` 事件返回 `404 unknown-session`。当时的扩展在连续三次失败后退出接入，需手动重新 `/connect-bot`，这不是现行外部扩展的重试契约。多实例身份、路由及隔离不在本决策范围内。
