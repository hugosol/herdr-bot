# 06: 用真实 Herdr 验证关闭效果与历史保留

**What to build:** 在测试拥有的安全隔离环境中，自动经本功能的真实派发与 manager 完成路径关闭专属 Herdr Tab，证明关闭确实移除目标、终止其中受控终端进程，同时保留无关 Tab 和 Chat 历史。

**Delivers:** P22

**Blocked by:** 02: manager 完成后非阻塞关闭本次执行 Tab（提供本功能的真实完成关闭路径）。

**Status:** ready-for-agent

- [ ] 使用真实 Herdr 依赖及本功能的派发和 complete 路径取得证据，不直接调用关闭命令代替业务触发，不使用测试 adapter、后端“成功”日志或仅有 `completed` 状态冒充外部效果。
- [ ] 建立可确认所有权的验收专属 Tab、Chat、受控终端进程及隔离运行数据；记录关闭前目标身份和进程存活证据，不能触及用户对话或工作 Tab。
- [ ] 在验收 Workspace 中预先保留至少一个测试拥有的无关 Tab，避免关闭最后一个 Tab 意外清空 Workspace；关闭前后记录并核对其身份与保留状态。
- [ ] 节点启用自动关闭并由 manager 合法完成后，记录目标 Tab 被移除及其受控终端进程已终止的证据，核对目标确为该次节点执行关联的 Tab；不承诺终止脱离原会话的任意 daemon。
- [ ] 关闭前准备具有可独立核对内容的测试 Chat 历史，关闭后经既有历史访问能力确认仍可取得原生历史内容；历史会话列表仅保留一条登记或只存在 session ID，不足以证明聊天历史未删除。不将恢复 Chat 当成重新派发。
- [ ] 本票拥有 P22 的完整真实依赖自动化验证和必要适配；不重复认领 04 的日志检查或 05 的恢复不补关检查。单独通过本票不代表 P1–P21 已验收。
- [ ] 沿用 Herdr 自身关闭和确认语义，不强制绕过额外确认。验收缺少安全隔离、真实依赖或历史访问条件时，完成可达准备并报告具体阻碍与未验证证据；不得使用用户资源凑验收，不把替身成功或 skip 算作通过，不在缺少 P22 证据时关闭票据。
- [ ] 验收全自动执行，不预留人工操作代替约定证据；遵守仓库测试及进程清理规则，持续消费输出，清理测试拥有的剩余资源，并同时保留原始验证错误与清理错误。
- [ ] 在受影响文档记录安全隔离前提、自动化执行入口和证据取得方式；实际验证结果记录于执行日志，不将未执行场景表述为通过。
