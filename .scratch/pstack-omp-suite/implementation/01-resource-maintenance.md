# 01: 可审查、可重现且有所有权边界的资源维护命令

**What to build:** 维护者从固定上游快照、明确清单与具名映射生成真实资源，独立审阅本地适配和上游变化，并能只读检查一致性；失败不得掩盖副作用或误删非生成资源。

**Delivers:** P5, P6, P7, P8, P9, P10, P12, P13

**Blocked by:** None (can start immediately)

**Repositories:** toolkit

**Status:** ready-for-agent

- [ ] 通过 S1 交付公开维护命令：在 toolkit 根使用 bun run pstack:build 生成，bun run pstack:check 只读检查，bun run pstack:preview 审阅具名适配差异，bun run pstack:upstream -- --local <绝对上游目录> 比较指定基线；提供完整调用帮助、退出语义和可复制示例。这些是本票新增的交付接口，不是已有命令。
- [ ] 每项文本适配有稳定名称和原因，预览、差异、错误能够定位操作；用具有独立预期的真实适配样例审查原因是否对应一个可独立变化的行为。
- [ ] 独立编写缺失锚点、重复／歧义锚点、冲突编辑样例，均非成功退出并报告具体操作；记录失败前已发生的文件效果，不承诺整包事务。
- [ ] 构建前后独立读取上游快照字节；独立字面文本和二进制样例的交付字节符合预期，仅允许明确声明的文本换行规则。
- [ ] 同一有效输入重复生成结果一致；手改交付产物后检查明确失败。检查的一致／不一致两种情况均不改输入、产物内容或目录清单。
- [ ] 分别植入已知上游变化和映射变化，比较／预览输出对应独立已知差异，不调用生成算法反算期望。
- [ ] 成功、失败及过期生成资源清理都保留植入的非归属文件和用户证据，独立读回；不支持运行中更新，不引入并发发布平台。
- [ ] 交付 bun run test:pstack 作为本特性的受影响测试分区入口，后续 toolkit 票把各自拥有的自动用例纳入此入口；本票验证维护机制，不能以入口注册或源码文本断言冒充行为测试。

## 契约与执行边界

依据：[已批准 contract](../contract.md)（S1 套件维护命令、S2 Suite 选择及 Chat 发起／恢复、S3 OMP 原生会话交互）。以 P 编号和本票 coverage 为验收依据，不改 spec／contract 的承诺。

只保证迁移内容语义和代码机制，不测试模型自主路由、评分、综合、授权服从或输出质量；内容审查由 agent 完成，不转成人工必验。受控 adapter 只证明请求和真实工具交互。不得用源码字符串、参数正确或产物存在替代消费者可见效果；期望来自独立指定输入、批准上游方法或独立字面结果。

复用现有原生机制和测试归属，已有覆盖不重复新增。修改前读取目标仓的适用指引。使用 owned 临时配置、Git 仓库、端口、页面和可追踪进程，保留证据并只清理所属资源。缺依赖、错误或未运行必须如实报告。不要安装／修改宿主、全局模型或生产配置来伪造通过。

更新生成资源／模型前停止使用同包的 pstack 会话，完成后重新发起；不引入热加载、在线快照或跨进程强制停用检测。正常并行会话不被禁止。先完成代码、内容审查和全部可执行自动检查，再进行 H1/H2 人工验收；人工未确认项继续标为未验证，不阻止其他工作。

## 验证入口

在本票 toolkit worktree 根执行 `bun run test:pstack` 中本票拥有的分区，并通过本票指定的 S1/S3 行为场景；TypeScript 变更运行 `bun run typecheck`，harness-facing 变更包含实际 OMP dock。完成时按目标仓指引检查受影响消费者，保留命令和原始退出；不以全仓测试替代本票行为证明。
