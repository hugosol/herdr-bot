# 08: 完成桌面与移动端的模板管理和 Bot 创建

**What to build:** 能访问当前 herdr-bot 实例的电脑和手机均可管理共享模板，并从 zone 创建 Bot；触控、键盘输入、创建阶段及成功/失败结果在移动布局中可用，不新增账号要求，也不改变 connect-bot 会话事件写入边界。

**Delivers:** P45。

**Blocked by:** 02 — 从 zone 创建默认配置 Bot，贯通进展与结果。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 桌面与移动尺寸的真实浏览器分别实际完成模板新增、读取、编辑、删除及从 zone 打开创建弹窗、选择模板、输入任务和提交；不是仅截图检查布局，也不是仅观察 mock 页面。
- [ ] 实际修复窄屏布局、溢出、触控目标和键盘输入问题，确保命名预览、多行 prompt/input、配置选择、阶段及定位结果可读可操作，用户可自行关闭弹窗。
- [ ] 延迟就绪和提交以稳定观察两个阶段，并分别操作成功与失败结果；不要求手机用户绕回电脑完成页面上已承诺的操作。
- [ ] 用独立客户端证明模板共享，以真实局域网浏览器请求验证模板管理和创建可达，不误套 connect-bot 会话事件的同机来源限制；不新增账号、token 或权限系统。
- [ ] 保持原有会话事件仅同机来源可写；用既有公开边界观察新增浏览器意图和会话写入是不同能力，不能为手机创建放宽会话登记边界。
- [ ] 本票可在 02 后立即开展，不人为等待 03–07。使用已完成的真实产品路径验证并修复移动交互；最终交接对其后合入的配置、输入和结果行为做必要移动回归，不重复认领其他票的业务测试。
- [ ] 完成全部可执行实现、自动检查和桌面/移动尺寸实际浏览器验证后，准备 H2 的访问入口、验证证据及简短日常手机验收步骤。局域网或实机条件确实不可用时明确报告真实阻塞，不用尺寸模拟声称实机通过。

## Human-led coverage preparation

本票只负责 P45 的 H2：用户在日常手机确认触控、键盘输入、创建阶段和结果体验。移动尺寸自动浏览器验证不等于真实手机确认。人工项未确认时保持未验证，不暂停其他自动工作。

H1 的证据仍分别由 02（Workspace/cwd/就绪/提交确认）、03（四组 agent/model）、04（Skill/单轮输入）、05（独立对象/新对话）准备。最终统一交接可以合并成一轮验收，但不以“汇总证据”为本票增加其他 blocker 或重复认领测试。

## Contract boundaries

依据已批准的《Contract — Bot 模板管理与从 Zone 创建 Bot》及来源 spec，沿用 S1/S2 和 ADR 0004/0006 的既有会话边界。本票不增加公网访问方案、身份系统、创建结果恢复、Bot 生命周期页面或 connect-bot 自动接入。
