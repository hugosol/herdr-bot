# 05: 保证对象身份、模板快照与独立新对话

**What to build:** 用户每次创建得到独立 Bot，即使同一 zone 的两个 Bot 显示名相同，也分别收到自己的任务。创建使用被接受时的模板；编辑或删除模板只影响后续选择，不改变进行中的创建或已有 Bot。

**Delivers:** P3, P12, P13, P24, P39, P40, P48。

**Blocked by:** 02 — 从 zone 创建默认配置 Bot，贯通进展与结果。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 同一 zone 两次公开创建在独立外部观察中具有不同 Tab、初始 Pane 和 agent 目标，不复用已有对象。
- [ ] 移除命名规则中的实例标识后连续创建，两组对象显示名完全相同，无自动后缀。使用独立对象标识及符合 Herdr 要求的控制别名，不以显示名定位，也不让别名互相覆盖。
- [ ] 两次同名创建使用不同的预写普通任务，外部记录显示各自正确收到自己的配置及输入；不依赖 04 的 Skill/复杂正文实现。
- [ ] 先保存旧字面配置，再编辑为新配置，下次创建的外部执行记录匹配预写新配置，而不是实现计算的期望。
- [ ] 挂起一次已接受创建的启动，由另一独立客户端编辑模板；本次仍按旧字面快照执行，下一次使用新配置。验证范围涵盖会影响创建的模板字段，不持有可变模板引用。
- [ ] 创建后编辑并删除模板，独立外部查询确认已有 Bot 的显示名、对象目标和运行未被重写或关闭；本票不重复认领 01 的删除后不可选测试。
- [ ] 预置同 cwd 的旧对话，验证实际新会话启动选择，不以新 Tab 单一证据证明新对话。覆盖 OMP 隐式续接/autoResume 设置，不加载旧上下文；Pi 同样启动独立对话。
- [ ] 完成适用自动检查和实际运行观察。会话身份来自真实外部标识或可独立观察的上下文，不伪造 Herdr 未提供的标识，不要求 connect-bot 接入。

## Human-led coverage preparation

本票负责 P24/P48 的 H1：准备四组合的新建对象标识与创建前后对照，以及已有同 cwd 旧对话、新对话启动的完整复现。包含启用 OMP autoResume 的真实环境；会话标识可得时提供独立旧/新标识，否则提供真实上下文对照并说明观察限制。与 02/03/04 共用一轮四组合验收，不要求重复执行。先完成实现和自动检查，待用户确认的真实部分保持未验证。

## Contract boundaries

依据已批准的《Contract — Bot 模板管理与从 Zone 创建 Bot》及来源 spec。沿用 02 从一开始建立的对象身份和接受时快照，不先引入再保留名称定位或旧对话兼容路径。不扩展 Bot 生命周期管理、模板并发编辑合并或后端崩溃恢复。
