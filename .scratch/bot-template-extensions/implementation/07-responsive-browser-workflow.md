# 07: 完成桌面与移动视口的真实操作验收

**What to build:** 在桌面和移动尺寸的实际浏览器中，完整操作三步模板编辑、命名编辑器、扩展选择、摘要及错误修正，修复阻断使用的布局和触达问题，并提供可复现的截图与操作记录。

**Delivers:** P49

**Blocked by:** 05 — 让旧页面和失效模板可辨认、可拒绝、可修正。

**Status:** in-progress

## Acceptance criteria

- [x] 在真实生产页面的桌面和移动视口分别完成新增及编辑流程，实际操作现有字段、命名规则编辑和四类字段插入、扩展复选框、步骤前进返回、摘要及明确保存。
- [x] 操作并核对步骤往返保留具体草稿值与勾选；可见控件能被实际操作，布局没有阻断使用的横向溢出或不可触达内容，不只检查元素存在。
- [x] 在两种尺寸实际经历持久保存失败、失效选择提示及修正、创建前依赖检查失败反馈；能理解原因并继续修正，而非只提供正常状态截图。
- [x] 在发现阻断问题时修复真实界面并重新操作受影响路径；保留原命名编辑、模型联动和错误语义，不以隐藏字段或只读替代解决布局问题。
- [x] 提供桌面及移动视口截图、视口信息、实际操作记录和复现步骤，明确使用实际服务、元数据和接口，不使用原型内存演示。
- [x] 明确移动视口仅证明 P49，不宣称真实手机触摸、软键盘或输入环境已通过；将证据交给 08 复用准备 H2。

## Verification and scope

依据：[批准契约](../contract.md)、[规格](../spec.md)。本票拥有 P49 的真实浏览器检查和证据。复用既有行为验证，不为私有 DOM 组织、源码文字或实现细节新增永久测试。

真实手机最终判断为 P50/H2，由 08 准备和记录，不是本票可以用模拟视口替代的结果。01 的数据默认布局不阻塞这里的界面工作，最终配置整合由 08 检查。
