# 04: 按模板扩展集合检查依赖并创建 Bot

**What to build:** 创建 Bot 只使用模板选择，在产生 Herdr Tab、agent 或输入提交之前自动校验当前配置及本次所需入口。通过后关闭扩展自动发现，显式加载固定项与模板所选项，继续既有就绪、初始输入提交及部分失败保留现场流程。

**Delivers:** P16（实际启动部分）、P21、P22、P24、P25（扩展启动解释）、P26（扩展后续创建）、P33、P34、P35、P38、P39

**Test owner for:** P16 的固定项启动与直接请求不可取消覆盖；P25 的扩展动态启动映射覆盖；P26 的扩展后续创建动态读取覆盖。03 拥有展示/保存覆盖，02 拥有 P25/P26 现有字段覆盖；全部完成才整体完成。

**Blocked by:** 03 — 交付可持久保存扩展选择的三步模板编辑。

**Status:** in-progress

## Acceptance criteria

- [x] 真实创建弹窗只选择模板并填写本次 input，不提供扩展选择；直接请求不能替换模板选择、取消固定项或提交任意入口绕过校验。
- [x] 公开创建自动读取当前元数据并校验模板选择及适用关系；检查本次全部固定和所选扩展入口存在、为文件且可读，无需用户另按检查按钮。
- [x] 以真实隔离文件分别制造固定项和可选项的缺失、目录冒充文件及读取拒绝；公开创建明确报告具体扩展、入口及原因。
- [x] 元数据关系有效时，未选扩展入口缺失不阻止所需文件齐备的合法组合创建；不把未选依赖缺失误当全局结构非法。
- [x] 对元数据、模板失效选择及入口故障逐类经公开创建观察：响应与实际页面明确尚未创建 Tab、启动 agent 或提交输入；独立外部调用和对象记录证实三个副作用均未发生，不只检查文案。
- [x] 六种组合（OMP 零项、仅 codebase-tools、仅 connect-bot、两项；Pi 零项、codebase-tools）均通过公开创建验证原生关闭自动发现的开关与准确显式入口集合；始终包含对应 Agent 的 model-cost，不修改用户或项目 agent 配置。
- [x] 不选 connect-bot 仍按既有成功定义创建，不等待 chat 登记或扩展接入，不伪造登记、接入或自动跳转 chat。
- [x] 同一进程外部修改扩展入口映射后，相同已保存模板标识的新创建使用独立预写新入口，无需重存模板或重启；启动参数不来自模板内映射副本。
- [x] 通过检查后先确认 Herdr agent 就绪，再提交一次原生合成初始输入，确认提交后才报告成功；后续失败保留真实 Tab/Pane/agent 定位，不删除、重建、重发或伪造成功。
- [x] 检查不导入或执行扩展、不调用模型或余额/账号探测；用可辨认执行副作用的入口和独立外部记录观察。反馈仅承诺文件检查结果，不宣称扩展、Skill 初始化或执行成功，不承诺检查后文件不再变化。
- [x] 同步创建及错误说明，保存独立受控 Herdr 证据供 08 复用；明确调用正确不等于真实 OMP/Pi 加载通过。

## Verification and scope

依据：[批准契约](../contract.md)、[规格](../spec.md)。本票完整拥有 P21/P22/P24/P33–P35/P38/P39 自动检查，包括 P35 中元数据、持久选择和入口故障的无副作用测试；05 不重复认领这些测试，而负责旧页面及修正路径。

使用公开 HTTP 与实际页面驱动，独立记录外部调用和对象，文件故障使用真实隔离文件。六组合预期集合、开关及顺序独立预写，不由实现参数组装生成。真实加载的 ambient 对照和人工 H1 最终判断由 08 管理；并发完整快照由 06 完成。
