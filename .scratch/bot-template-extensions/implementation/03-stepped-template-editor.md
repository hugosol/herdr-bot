# 03: 交付可持久保存扩展选择的三步模板编辑

**What to build:** 在 bot 入口按“模板预设 → 扩展配置 → 确认保存”完整新增、查看、编辑和删除模板。保留原字段及命名编辑能力，支持 Agent 对应的扩展选择和清晰摘要；只有明确保存成功才更新共享持久结果，失败不损坏旧模板。

**Delivers:** P1、P2、P3、P4、P5、P6、P12、P13、P14、P15、P16（展示部分）、P17、P18、P19、P20、P25（扩展展示、保存校验及稳定标识持久化）、P26（扩展重新打开编辑与保存）

**Test owner for:** P16 的页面和摘要覆盖；P25 的扩展展示、保存适用性校验及稳定标识持久化覆盖；P26 的扩展重新打开编辑与保存覆盖。这些承诺的启动覆盖由 04 拥有，P25/P26 的现有字段覆盖由 02 拥有；全部覆盖完成后才整体完成。

**Blocked by:** 02 — 由动态元数据驱动现有模板选项与启动映射。

**Status:** in-progress

## Acceptance criteria

- [x] 真实生产页面完成 bot 入口模板新增、查看、编辑、删除完整生命周期，独立公开读取确认结果；删除不向既有 Bot 发出关闭调用。
- [x] 新增和编辑均按模板预设、扩展配置、确认保存顺序可达；前进、返回保留预写的多字段、多行草稿和具体扩展勾选，不以页面存在代替值验证。
- [x] 步骤导航不保存。导航后独立读取仍为旧样例，明确保存成功后才读到新样例；拒绝保存不显示成功。
- [x] 名称、命名规则、Agent、model、thinking、Skill、prompt 均可按原语义编辑和读回，不以只读控件代替；保留命名规则编辑、四类字段插入及混合固定文字的独立预写示例预览。
- [x] OMP 只提供其 codebase-tools、connect-bot 两项，Pi 只提供其 codebase-tools；页面与公开选项一致，直接保存请求不能跨 Agent 选用不适用入口。
- [x] 新模板可选扩展初始为空，保存读回仍为空；OMP 四种、Pi 两种允许组合得到准确稳定标识集合。固定扩展不计入勾选项。
- [x] 对应 Agent 的 model-cost 独立显示为不可取消固定项，摘要与可选项明确区分；本票不以展示证明真实加载。
- [x] 从 OMP 两项已选切至 Pi 再切回 OMP，model、thinking 为默认，扩展为空；不恢复旧隐藏勾选，不隐式继承同名跨 Agent 入口。
- [x] 确认摘要按独立样例准确展示全部现有字段、固定项、所选项及自动发现关闭，并与最终公开保存结果一致。
- [x] 公开保存后第二独立客户端及真实程序停止、重启后按标识读到相同模板与扩展选择。
- [x] 在真实隔离目录制造持久写入故障，页面明确反馈失败而非成功；独立重读及真实重启后此前模板保持原样，不以 mock 写入返回值证明。
- [x] 同一进程外部修改扩展选项后，重新打开编辑及后续保存使用当前元数据；持久结果仅记录稳定选择标识，不保存入口映射副本。更新用户操作说明。
