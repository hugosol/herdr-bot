# 01: 集中运行数据并完成一次性切换

**What to build:** 使用契约与规格指定的集中运行数据布局启动、保存模板和创建 Bot。只迁移 zone 登记，清除已授权的旧模板和旧会话；切换后不再读取旧位置，正常重启保留新数据。保留显式持久位置配置，不改变 zone 实际目录或临时状态生命周期。

**Delivers:** P40（运行数据布局部分）、P41、P42、P43、P44、P45、P46、P47、P48

**Test owner for:** P40 的运行数据布局覆盖；完整 P40 在 02 的元数据布局覆盖完成后才完成。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 默认与随附配置使用规格规定的运行数据位置；在真实隔离磁盘上经公开保存、创建及真实进程重启观察实际结果，不以私有路径函数返回值作为证据。
- [ ] 显式指定非默认模板持久位置后，公开保存及重启读取均使用该位置；默认和显式配置均不自动读取或回退旧位置。
- [ ] 新目标不存在时，旧 zone 登记完整迁入目标，公开读取保持原登记信息及所指目录；旧源不再被读取，zone 内容通过逐字节或等价外部证据确认未改动。
- [ ] 新旧 zone 登记内容不同时保留新目标原样并删除旧源，不合并、不覆盖新内容，也不按冲突停机处理。
- [ ] 一次性切换清除授权范围的旧模板和旧会话，不迁移、不恢复它们；旧模板清理后公开列表为空。旁置无关文件、zone 内容保持原样，不发送 agent 关闭指令。
- [ ] 切换后新建模板和会话样例，连续两次真实进程重启仍保留新数据；正常启动不会重复执行清空新数据的行为。
- [ ] 缺少运行数据目录时可创建；公开创建两个 Bot 后观察独立的新会话位置及无旧上下文的文件证据。目录或写入失败时明确失败，不假报成功。
- [ ] 在使用交付忽略规则的隔离真实 Git 场景，运行数据及临时文件不进入候选跟踪集，手工元数据可跟踪；不对用户运行数据执行添加或提交。
- [ ] 重启不恢复会话登记、关机意图或创建进度，不因整理数据位置扩大既有生命周期 ADR 的范围。
- [ ] 同步随附配置、运行说明及忽略规则；不新增旧模板兼容、双位置回退、数据库服务或 zone 实际目录搬迁。

## Verification and scope

依据：[批准契约](../contract.md)、[规格](../spec.md)。目标布局及授权清理范围以规格和契约 B1/B2 为准。测试预期使用独立预写的登记、文件内容和公开结果；使用真实隔离文件与真实程序启动，不 mock 文件写入结果。

本票拥有 P41–P48 的约定自动检查；P40 只拥有运行数据布局检查，02 拥有独立元数据布局检查。元数据解析和三步编辑不属于本票。01 与 02 可先行，03 不被本票阻塞；最终交付配置的合并验证由 08 执行。
