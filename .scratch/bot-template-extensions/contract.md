## Seam decisions

|Seam|Exposes|Hides|Alternatives considered|Reversibility|
|---|---|---|---|---|
|S1：真实浏览器操作 interface|用户实际看到和操作的步骤、字段、草稿、选项、摘要、反馈及可操作性；H2 在同一 interface 上观察真实手机。|UI 内部状态组织、私有渲染划分、事件处理和 DOM 实现细节；不以原型模拟为生产 adapter。|只检查 HTTP 不能证明真实编辑器和步骤操作，因此不采用；复用现有浏览器操作 interface，不另建测试专用 interface。|可更换内部实现，只要操作承诺不变；调整用户流程需先修订契约。|
|S2：公开 HTTP interface，联合观察外部创建结果|公开模板及选项操作、请求拒绝/接受与创建结果；独立 Herdr 调用和对象证据；H1 在真实 Herdr→OMP/Pi 下观察实际加载。|元数据解析、模板验证、参数组装、任务推进和外部 adapter 的内部实现；不冻结 JSON 错误表示或私有函数。|仅凭返回值/渲染值不足以证明零副作用及实际启动参数；调用记录又不足以证明真实 agent 加载，因此保留两种外部证据。无需新增内部 interface。|可替换内部构造；变更公开消费者约定或取消独立外部观察需修订契约。|
|S3：程序启动与持久文件 interface|启动成败、诊断、真实磁盘效果、重启保留、切换清理、Git 跟踪策略和显式持久位置配置。|存储实现、文件写入过程和迁移内部组织；不指定数据库抽象、私有辅助函数或测试专用入口。|只测内存或页面不能证明持久与失败机制；不用新的存储 port 包裹单一实现，复用已有进程和文件观察方式。|内部存储可变，但用户配置和已批准数据效果不能静默改变；后续引入其他持久介质时重审相关承诺。|

### Dependency 分类与证据约束

- **In-process**：模板草稿及已接受创建的状态逻辑由 S1/S2 的外部结果观察，不为内部计算额外暴露 interface。
- **Local-substitutable**：文件系统使用隔离的真实文件和真实故障，验证磁盘而非 mock 读写返回值；Herdr 已有生产 adapter 和受控测试 adapter，受控 adapter 提供独立调用记录，不只回显期望。
- **True external**：真实 OMP/Pi 的发现及加载行为需要真实执行证据，留在 P23/H1；原生参数正确不等于扩展执行成功。
- 本功能没有新增需要设计的 **Remote but owned** port；不为未来假想部署添加 seam。

### 已批准取舍及原因

- 用户明确批准 S1–S3。放弃仅网页或仅 HTTP 的单 seam 方案，因为它们无法同时区分可操作性、持久性、真实加载及零外部创建的违约情景。私有解析和选择逻辑仍保留实现自由。
- **B1：保留显式持久位置配置**。不采用强制唯一位置并删除现有配置项，因为用户明确要求保留；改变默认与交付配置不等于移除用户已有配置能力。
- **B2：zone 新目标优先，删除旧源**。不采用冲突阻断，也不合并或以旧覆盖新，因为用户明确不需要保留该冲突下的旧登记。此规则仅处理已授权切换的旧登记，不能扩展成删除任意用户文件。
- **Rapid iteration**：用户在 H1/H2 提议后明确选择快速迭代。自动实现及可执行验证由 agent 完成；真实环境最终加载判断和实际手机判断分别归 P23/H1、P50/H2。不采用全自动模式是本次验收责任选择，不是缩减承诺。
- 文件检查存在检查与执行之间的外部变化窗口；不增加执行扩展的预检、文件锁、账户探测或付费验证来消除它，继承 spec 的保守检查范围。
