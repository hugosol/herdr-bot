# 08: 完成跨流程验收与手机实机证据包

**What to build:** 在完整交付进程上验证文件功能与既有固定操作、会话和全局关机行为互不破坏，主动查询不受自动刷新节流阻碍，本地事件不变成持续远端检查。全部实现与自动检查完成后，为用户合并准备唯一的手机实机 H1 验收包，不把 Git 正确性或实现修复交给人工。

**Delivers:** P3, P4, P26, P27, P28, P41, P46

**Test owner for:** P42（本地文件事件不造成持续自动 fetch 的跨流程用例；按需检查及 Sync 前必查测试归 06）

**Blocked by:** 06: 按现有 upstream 与配置安全 Sync; 07: 用真实文件事件刷新并报告监听健康.

**Status:** ready-for-agent

依据已批准的 [contract](../contract.md) 与 [spec](../spec.md)，验收模式为 Rapid iteration，接缝仅为 S1/S2。此票是指定覆盖的集成验证切片，不是前面各票推迟实现或测试的兜底票。依赖通过传递关系已包含 01–05。

## Acceptance criteria

- [ ] 01–07 的实现与其各自分配的全部自动检查已完成；本票发现的问题由 agent 修复并复验，不交用户修复，也不把既有自动责任转成人工检查。
- [ ] 回归固定启动/停止行为、会话读取与业务交互、全局关机提醒及取消语义。跨三个 tab 的提醒仍可见，不改变会话与关机权威来源、生命周期或固定操作执行资格；沿用 ADR-0004/0005/0006。只用安全记录型关机能力，不调用真实关机。
- [ ] 在真实自动刷新窗口内分别交错进入 workspace、回到页面、手动刷新、Commit/Sync 完成和提交前复核，独立改变文件/分支并核对实际页面及仓库结果，证明这些路径不使用节流缓存代替新查询。不能只断言刷新函数被调用。
- [ ] 真实监听期间本地文件及 Git 元数据事件不造成持续自动 fetch；独立推进隔离远端，核对实际本地远端引用/检查时间不被本地事件更新。主动检查或 Sync 前必查仍按 06 行为生效。此项唯一拥有 P42 的该交叉用例。
- [ ] 独立调用者能够使用约定浏览与 Git 操作；非同机来源的会话事件写入仍被原边界拒绝且不改动会话。检查公开操作范围，没有任意命令、脚本或终端入口，不把会话写入限制扩张为禁止手机 Git 操作。
- [ ] 对新增功能的部署/使用说明保留可信局域网无认证提醒：可访问服务的设备可能读取已登记敏感内容并触发已开放 Git 写操作。不得宣称来源校验等于认证，不增加登录或公网部署能力。
- [ ] 先完成全部实现、分配的自动检查、真实浏览器及隔离 Git 验证，再开始 human-led H1。H1 不是暂停其他可执行工作的理由。
- [ ] 合并准备 P4/P26/P27/P28 的 H1 包：真实窄屏浏览器截图、实际可用局域网访问步骤、可复现的隔离场景及确认/取消弹框截图；列出顶层 tab 触摸、逐层返回、diff 滚动、软键盘出现后输入框/主按钮可达性和确认/取消触摸检查项。
- [ ] H1 包中记录可用环境及待用户补充的手机型号、系统、浏览器；尺寸模拟不得冒充手机实机通过。用户检查使用安全隔离场景，不要求人工验证 Git 正确性或向业务远端推送。
- [ ] 最终交接分开报告自动检查证据与 H1 待确认项。用户确认前不勾选实机验收通过、不宣称相关承诺全部完成；本票保持 in-progress 等待 H1，不能仅因 agent 证据准备完毕直接 closed。若有真实阻塞，如实列出已尝试内容与缺失条件。

## Verification boundaries

真实宽/窄屏浏览器与真实交付进程完成自动检查，文件、仓库与 bare 远端全部隔离；真实 Git 副作用由独立树/索引/历史/引用证据证明。不得用固定模拟输出、成功文案、私有函数调用或 DOM 存在替代实际行为证据。不得修改用户工作仓库、推送业务远端或执行真实关机。无需再次评审契约已明确的接缝、非交互时限和 diff 两侧限额，不新增功能范围。
