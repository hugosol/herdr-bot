# 02: 在 workspace 边界内只读浏览完整目录

**What to build:** 用户进入已登记 workspace，浏览完整目录树并选择文件只读查看。电脑使用左树右内容，手机逐层进入并明确返回；切换顶层 tab 后保留浏览位置。隐藏文件、被忽略文件、忽略规则文件与 Git 元数据均可浏览，任何公开读取都不能越出登记根边界。

**Delivers:** P5, P10, P12, P13, P14, P25, P26, P43, P44, P51, P54

**Blocked by:** 01: 登记并共享服务器 workspace.

**Status:** ready-for-agent

依据已批准的 [contract](../contract.md) 与 [spec](../spec.md)，通过 S1/S2 验收。普通目录只有浏览能力；不提供在线编辑、上传、下载或初始化仓库。

## Acceptance criteria

- [ ] 目录输出与独立创建的真实文件集合一致，包含隐藏文件、ignored 文件、忽略规则文件和 Git 元数据；页面可选择相应文件读取。浏览树反映磁盘实际存在的项目。
- [ ] 普通目录没有可用 Git 变更视图或 Commit/Sync 控件；本票不开放 Git 写入口。05/06 必须分别验证直接写请求不能绕过普通目录资格限制。
- [ ] 所有本票公开目录/内容读取入口拒绝根外路径、遍历路径、符号链接、Windows 目录联接及路径替换越界反例。根外链接显示目标和不可进入原因，不读取目标内容。真实 Windows 链接/联接证据不能由替身代替。
- [ ] 读取前后独立核对文件内容与真实索引语义未变；允许 Git 只读查询正常的非语义缓存活动，不将其误判为暂存。
- [ ] 按内容识别文本，不强制后缀白名单；无后缀文本可读，伪文本后缀二进制给出明确不可文本预览原因。含 HTML/script 的文件在真实浏览器中仅作纯文本展示且不执行。
- [ ] 单文件预览默认上限为 1 MiB，后端可配置；验证精确字节边界和越界，超限不加载完整内容，不将受限结果伪装成完整内容。
- [ ] 沿用启动期配置惯例：旧配置缺少新段仍可启动，预览限额缺省、合法覆盖、无效类型及不合法值有独立验证；非法配置明确拒绝而非静默回退。不固定配置键名或结构。
- [ ] 外部删除目录或改变可访问条件后，公开读取和页面明确报错，不伪装为空目录或干净仓库。
- [ ] 桌面真实浏览器验证左树右内容、选择与滚动，并留截图；窄屏真实浏览器验证进入、返回与列表位置恢复，不仅断言 DOM 存在。
- [ ] 当前页面内跨顶层 tab 往返保留 workspace、展开状态、所选文件和浏览滚动；整页刷新不要求恢复临时状态。进入或回到页面、手动刷新读取当前事实，不预设可复用自动刷新缓存；节流交叉验证归 08。
