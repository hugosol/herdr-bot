# 05: 经审查复核安全完成整仓 Commit

**What to build:** 用户在变更列表上方填写提交信息，经过一句确认后，服务重新核对已展示的审查版本，再暂存本仓库全部符合 Git 规则的最终变更并提交，不自动推送。审查失效、执行阻塞或失败时给出真实反馈，不能静默纳入未审查内容。

**Delivers:** P2, P5, P6, P10, P11, P20, P22, P27, P28, P29, P30, P31, P32, P36, P37, P38, P43, P45, P47, P48, P49, P51, P53, P54

**Blocked by:** 04: 审查最终内容与完整 diff.

**Status:** ready-for-agent

依据已批准的 [contract](../contract.md) 与 [spec](../spec.md)，通过 S1/S2 交付完整安全 Commit。不得先开放写入口再等待后续票补串行、复核或超时；不扩展为任意命令平台、网页凭据、手动暂存或恢复工作流。

## Acceptance criteria

- [ ] 变更列表上方常驻提交信息与主按钮；有普通待提交变更且无阻塞时提供 Commit，页面与直接请求都拒绝空信息。当前页面跨顶层/内部视图往返保留输入。
- [ ] Commit 只弹一句确认消息及确认/取消，不重复列出 workspace、分支、文件数、信息或清单。取消时通过独立核对真实索引、提交与引用证明没有 Git 写入。
- [ ] 确认后以已展示审查版本重新查询并核对分支、HEAD、索引、文件集合及完整内容。覆盖同路径同数量内容变更、外部暂存、HEAD 变化、切分支，以及超限/二进制内容变化；不能只比较路径、数量、预览片段或未过期缓存。
- [ ] 审查失效时拒绝当次提交，提示并刷新实际内容，保留提交信息，要求重新审查确认；旧审查不能向另一分支提交。不承诺原子锁住所有外部编辑器或 Git 进程，保留契约接受的竞争窗口。
- [ ] 检查通过后暂存全仓符合跟踪/忽略规则的最终变化，再 commit；既有部分暂存不缩小范围，不强添 ignored untracked。独立核对真实提交树、本地历史与隔离远端引用，证明范围正确且未 push。
- [ ] 不递归管理嵌套仓库及子模块内部变化；独立核对它们前后状态，内部文件不作为父仓库普通内容提交，父仓库自身已跟踪的 gitlink 引用变化仍正常纳入。
- [ ] 已初始化但无 HEAD 的仓库在页面以空树审查，符合规则的已暂存和未忽略未跟踪文件均绿色；确认后独立验证首个提交树。本票唯一拥有 P47 的完整端到端测试，不提供 git init。
- [ ] 本实例按同一实际仓库串行写入；不同调用者及路径别名并发 Commit 不重叠。资格由执行而非请求连接持有，与固定操作的既有执行资格无关。断线或终止尚未确认时不提前释放。
- [ ] 普通目录、detached HEAD、未解决冲突及未完成 merge/rebase/cherry-pick/revert 等流程在页面与直接请求均阻止 Commit，并明确原因。冲突解决但流程未完仍阻止，外部完成或撤销后刷新恢复；普通失败不误标冲突。无 upstream 不妨碍本地 Commit，不隐式修改配置。
- [ ] 缺失/不可访问目录或读取错误不当作可提交的干净事实，写请求明确拒绝；超限和二进制预览限制不改变提交资格与真实提交树。
- [ ] Git 沿用服务器既有非交互身份与凭据；需输入的编辑器、凭据、签名条件明确失败或超时，不新开终端/网页凭据流程，不覆盖 Git 策略伪造成功。
- [ ] 每条 Git 命令默认上限 300 秒且可配置；旧配置缺段保留默认，合法覆盖生效，非法类型/值拒绝启动。以较短配置验证阻塞执行及派生执行终止、失败短路与未确认停止时资格保持；不把本功能超时伪造成 Git 退出消息。
- [ ] 任一步失败停止后续步骤。真实 hook 拒绝 commit 时保留已成功暂存的实际索引，不自动回滚；页面显示 Git 返回的纯文本诊断及已有输出，不执行其中 HTML/script。
- [ ] Commit 中切 tab 不取消已接受执行，返回可见实际状态与结果；执行中重载默认会话列表且不重放。观察响应中断时显示未确认而非假成功或认定未执行，通过查询实际仓库状态恢复观察，不自动重试写入。
- [ ] 进入/返回、手动刷新、操作后刷新与提交前检查使用当前事实，不以自动刷新缓存代替；窗口交错集成测试归 08，本票不能因此推迟入口实现。
