# 01: 登记并共享服务器 workspace

**What to build:** 用户从 omp-bot 主界面的「文件列表」入口输入服务器目录路径，登记已有普通目录或 Git 工作树根目录。登记列表由同一后端实例持久保存，电脑和手机共享；取消登记不删除目录或文件。三个顶层入口调整为会话列表、文件列表、控制面板，每次打开或整页刷新默认会话列表。

**Delivers:** P1, P2, P4, P7, P8, P9, P50

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

依据已批准的 [contract](../contract.md) 与 [spec](../spec.md)。仅通过 S1 主界面公开交互、S2 交付进程公开交互验收，不新增私有模块契约。保持 ADR-0002/0004/0005/0006 的既有边界。

## Acceptance criteria

- [ ] 真实页面按会话列表、文件列表、控制面板排列；打开和整页刷新默认会话列表，不恢复上次 tab。控制面板名称不变。
- [ ] 桌面和窄屏三个入口等宽，有明确选中态与焦点，方向键及 Tab/Enter/Space 可操作；左右滑动不切换顶层 tab。迁移与新行为冲突的旧导航检查，不保留兼容 shim。
- [ ] 服务器路径输入接受真实存在的普通目录或 Git 工作树根目录，非法路径或不符合登记条件的输入明确失败；不用客户端文件选择器代替服务器目录。登记不初始化 Git，也不聚合多个仓库。
- [ ] 两个独立调用者读取同一登记列表，后端真实进程重启后列表仍在；不能以同页缓存或模拟重启作为证据。
- [ ] 取消登记前后，独立读取原目录与文件内容，证明未删除或更改文件。
- [ ] 登记只在持久化成功后显示成功。隔离验证存储写失败、读取失败及损坏内容；错误不伪装为空列表，也不静默覆盖原内容，再次读取与重启后核对原存储。
- [ ] 在真实浏览器演示完整登记、列表读取、失败反馈和取消登记流程；本票不是空白导航骨架。不得执行真实关机。

## Coverage partition and test ownership

表中仅列本票负责的分区；本票拥有其全部自动测试。跨票承诺须全部分区通过才完成。

| Promise | 本票覆盖项 | Ticket | Test owner | 其余覆盖归属 |
|---|---|---|---|---|
| P2 | 打开与普通整页刷新默认入口 | 01 | 01 | 05：Commit 中重载无重放；06：Sync 中重载无重放 |
| P4 | 等宽、选中态、焦点、键盘及无滑动切换的桌面/窄屏自动检查 | 01 | 01 | 08 准备手机触摸 H1 证据；用户确认 |

P1/P7/P8/P9/P50 的全部覆盖与测试由 01 独立负责。02 负责登记后实际读取目录和内容；不将其作为 01 的反向完成条件。

## Verification boundaries

使用隔离目录和隔离登记存储，真实进程验证持久化，真实浏览器验证导航。期望来自独立建立的目录与内容，不从 implementation 计算结果生成。测试结果与人工确认分开报告；本票不宣称 H1 通过。配置、登记格式、接口消息形状与内部模块依既有惯例选择，不在本票固定。
