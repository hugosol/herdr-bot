## Question

管理者工具如何覆盖合法运行流转，同时将策略选择与动作落实分开？

区分 Run、节点执行、交付、决定；形成动作／身份／前置条件／效果／拒绝条件矩阵。覆盖派发、报告、放行、等待、暂停、恢复、重试、停止的职责接口，故障动作细则由后续票据确定。首版没有额外业务校验；完成信号、交付与显式放行如何衔接必须决定。不得提供任意 setStatus 后门。
