- 覆盖追踪：自然语言人工介入与故障入口由观察票提供；工具加载、实际 Chat 启动及可信身份由接入票提供；新旧执行事实与提交一致性由持久化票提供；交接消息由已解决的通信票提供。开放提供者不视为已实现。
- 新增使用指引的交付覆盖缺口已落入[跨模块设计收敛与实施交接契约](10-spec-acceptance.md)的 Question：检查用户指南及管理者工具指引的交付组织与可操作性，保留该票原状态、claim 与恢复上下文。无需新增票据，暂无新增可毕业 fog。

## Question

管理者如何通过工具处置故障、暂停等待人工处理，并在收到 Chat 消息后恢复或重试？

确认后的范围：覆盖常见 failed 节点的状态恢复、独立新 Chat 重试及人工完成，明确人工补齐交接的责任，并纳入用户故障处理指南和管理者工具使用指引。不在实现前穷举复杂故障路径。

原问题还列出暂停准入、恢复、重试身份、会话复用、迟到反馈、历史保留、已放行／已被下游使用交付的处理、重复请求与容量；本轮按用户要求收窄为上述最小契约，具体处置和保留的下游分工见 Handoff 与 Lighthouse。重试配置继续消费字段契约，不增加自动恢复策略。
