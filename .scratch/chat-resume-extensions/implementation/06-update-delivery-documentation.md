**Delivers:** P21。P 编号引用本功能已批准合同。

**Blocked by:** None (can start immediately).

**Status:** in-progress

- [x] 解释恢复读取来源 Bot 最新 env config 与当前 Bot 选项目录，不是历史快照或版本回放；来源缺失／Bot 删除使用 agent 原生默认发现，有 Bot 时逐项过滤且空集合仍关闭发现。

- [x] 使用 Bot、Chat、zone、Herdr Workspace 等现行领域词汇，尊重已接受 ADR；不改写历史 ADR、历史证据或父级 spec／contract 来消除历史差异。
