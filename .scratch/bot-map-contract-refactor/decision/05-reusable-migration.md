## Question

怎样将用户选中的旧流程及相关定义转换为完整新格式，并可重复用于迁移清单中的其他流程？

- 逐字段、逐类知识规定旧到新的映射，区分确定性转换、语义重写和必须由用户判断的内容；未知内容不得猜测或丢弃。
- 定义迁移输入、输出、操作步骤、依赖范围、稳定 ID 和引用处理、共享对象冲突、已转换对象的识别及中断后的处理。
- 未迁移定义保留，不保证在新系统运行；用户可选择废弃，不默认批量迁移。
- 确定转换产物、原始备份及清单状态如何对应，如何避免覆盖未获授权的对象。
- 已确认提示词从其权威取用；本票不重复创作正文。
- 本票设计可复用方法，不提前执行全量迁移或编写生产迁移工具。
