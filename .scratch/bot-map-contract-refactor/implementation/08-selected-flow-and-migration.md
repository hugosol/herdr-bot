- [ ] 直接采用最终批准正文，保留四 Bot、三 Task 的稳定身份、名称、目标及 agent/model/Suite/初始 Skill 等非目标设置；Map 保留概要规划、转换、整图优化拓扑、zone、批准/关闭策略和 outline/map/handoff 接线。

- [ ] 业务正文迁入统一流程资料位置，独立 Task 与 node 指向同一正文；所有 Markdown 链接、裸路径及适用角色供给一起迁移，旧正文/过期入口/兼容跳转不再被消费。对应节点按条件读阶段标准，管理者不加载专属验收。
- [ ] 概要方案自包含、确认范围和转换条件齐备才正式交接；缺口/未决选择作为中间材料返回用户。转换/优化读取真实实现、忠实落实确认方案；共享修改列其他消费者并取得范围确认。采用批准正文与适用公开机制检查，不用静态匹配声称模型已遵从。
- [ ] 用户可调整默认保存/检查建议，不重复索取同一授权，不绕过代码约束；交付真实效果、执行/省略检查及未知项。03 的校验、02 的真实保存/并发拒绝用例不再重复编写。
- [ ] 迁移清单从实际配置的 Map 入口调查来源、用途、关联实现/资料、共享消费者、产物、待补及运行事实；只用未开始/迁移完成/废弃。转换后更新本流程实际产物和剩余问题，未经用户确认仍为未开始；未选择不算废弃，不列无关 Task 为独立迁移项。
- [ ] 未变格式的共享 Task/Suite/script/Skill/资料原位维护，不维护长期副本，不要求所有消费者同时迁移；其他流程复用既有调查/grilling 方法而非创建map业务答案，不预造未选流程验收。
- [ ] 本票拥有 P52/P54/P56/P58 隔离自动覆盖：在途执行/外部效果核对与暂停/退出/managed=false 的区别；只有明确确认的旧副本可删而正式/未处理/废弃对象保留；仅 chief 运行记录清理而 Chat/原生会话/zone/产物字节保留；仅迁入首条流程即可执行且 Markdown 清单不作为门禁。复用现有生命周期和文件操作，在隔离集合独立前后核对，不新增自动迁移平台或接触生产数据。P53 的 backup 在线排除 case 归 02；本票的稳定身份首条迁入场景同时覆盖 P53/P58，不重复建测试。P55/P57 产品 case 分别归 04/07。
