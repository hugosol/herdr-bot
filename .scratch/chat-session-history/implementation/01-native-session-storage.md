**What to build:** 从 zone 新建 Pi／OMP Bot 时，遵循 agent 自身正常的原生会话存储配置，不再覆盖或预分配专属原生会话目录。用户可通过原生发现机制找到这些对话，既有配置和旧会话文件不受本次功能改动影响。

**Delivers:** P23、P24；P25 的原生存储修正与旧文件保护分区。

**Test owner for:** P25 的存储修正前后旧主文件及附属文件保护；本票不单独完成 P25。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 移除 herdr-bot 对新 Bot 原生会话目录的覆盖、预分配及仅为该目录服务的创建前置条件；不保留旧策略的兼容路径，不引入替代性的强制新会话策略。
- [ ] Pi／OMP 均遵循自身有效存储配置；不启用、关闭或修改 autoResume、原生目录或其他 agent 全局配置，不把新建 Herdr Tab 宣称为一定产生新对话的保证。
- [ ] 受控 adapter 覆盖启动选择；分别运行隔离的真实 Pi／OMP，独立观察原生文件实际位置、引用及原生发现能力。启动参数回显、帮助文本、此前文件迁移结果均不替代真实落盘和发现证据。
- [ ] 使用隔离配置验证非固定默认位置的有效配置确实生效；独立比较运行前后配置，不修改用户真实全局文件或向已有用户对话提交测试输入。
- [ ] 隔离环境预放旧原生主文件与附属记录，比较改动流程运行前后的字节和目录清单，确认没有移动、复制、转换、删除或改写。此项为本票独占的 P25 存储修正覆盖；显式 register 与精确引用读取分别归 02、05、06。

- [ ] 准备 P23-H1 两种 agent 的有效配置说明、创建对象定位、实际原生引用、目录／header 证据与原生发现最小核对步骤。H1 只由用户在实际部署确认，不以受控 adapter 或隔离运行标为通过。
