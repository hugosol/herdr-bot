# 03: 历史稳定排序、分页与独立保留

**What to build:** 用户能够长期保留历史并按首次收录时间倒序逐页浏览，每页最多 50 条。当前登记注销、过期或 zone 取消登记不会删除历史；页面进入历史或翻页时读取最新持久结果，停留时不自动刷新。

**Delivers:** P07、P12、P13、P16。

**Blocked by:** 02: 成功 register 形成可持久读取的历史视图。

**Status:** in-progress

- [x] 历史按首次收录时间倒序；用不同预写服务端时刻和独立 ID 建立精确顺序，随后执行心跳、重复 register 和元数据更新，顺序不因这些事件提升旧记录。
- [x] 首次时间相同的记录在静止数据集中稳定翻页，不冻结具体次级排序选择；用精确集合证明不会因同时间记录漂移而不可访问。
- [x] 空集合、恰 50 条、51 条及多页集合均验证具体页内容、每页上限、前后页关系与首页／末页导航；静止集合的全部记录均可访问。
- [x] 实际桌面和手机浏览器操作上一页／下一页，确认导航与长内容布局可用，不把读取失败展示为空页。
- [x] 通过现有公开操作执行注销、zone 取消登记，并以受控时间推进当前登记过期；用超过一页的已知集合核对历史不减少。不增加年龄、数量淘汰或自动删除，不把分页截断当作存储淘汰。
- [x] 打开或整页刷新默认当前视图；进入历史和翻页均读取当时最新的持久结果。
- [x] 浏览器停留期间由独立客户端新增／更新记录，页面不自动刷新或实时重排；退出后再进入，或翻页后，取得最新结果。
- [x] 采用普通分页，不新增跨页冻结快照。说明并发新增时可能跨页移动，但不能以此掩盖静止集合漏项或持久数据丢失。
- [x] 从公开 HTTP 和实际浏览器观察结果，保留行为边界回归覆盖，并同步更新分页与保留说明。
