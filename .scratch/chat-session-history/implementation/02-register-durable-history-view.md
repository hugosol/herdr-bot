# 02: 成功 register 形成可持久读取的历史视图

**What to build:** connect-bot 的 register 被服务端接受后，将对话元数据保存为历史。用户可在 chat 内切换当前／历史两个互斥视图，在电脑和手机读取同一实例的持久记录；关闭浏览器或重启后端不丢失历史。

**Delivers:** P03、P06、P08、P10、P14、P15、P27、P28；P25 的显式 register 收录分区、P26 的正常注册／更新／重启分区。

**Test owner for:** P25 的不批量导入及旧对话显式 register 收录；P26 的正常 register、元数据更新及重启。两项 promise 均由后续分区共同完成。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 沿用现有 register 必填字段与来源校验；只有服务端接受的 register 触发收录。分别覆盖有效注册、缺可选元数据、未知非 register 写入和被拒绝来源，观察公开回执及历史结果。
- [ ] 使用可信完整 sessionId 标识记录；正常重复 register 更新同一记录，不按名称、cwd 或 ID 前缀误合并。不额外要求 agent 类型或原生文件路径才能收录。
- [ ] 后续有效元数据填充或更新已有值；缺失或无有效值不清空已知值。原生会话文件精确绝对路径允许作为内部引用更新，但不在页面展示，不读取正文。
- [ ] 提供服务端持久历史的公开只读读取；用已知记录重启隔离后端，再从独立客户端及浏览器上下文读回精确集合。浏览器刷新、关闭和重新打开不改变持久数据。
- [ ] 实际点击 chat 右上角三角按钮，验证当前／历史两个方向互斥切换、明确文字标签和不同面板底色，不仅依赖颜色或三角方向。
- [ ] 实际桌面和手机尺寸浏览器检查紧凑表格／紧凑条目，只展示名称、agent 类型、cwd、首次收录时间。长名称和长路径可读；无名称回退完整 sessionId，其余缺失展示值为 `—`，不得猜类型或以“离线”替代未知值。
- [ ] 历史不展示模型、来源、keepAlive、运行状态或关机监听操作；交付页面和已文档化公开 interface 不新增搜索、筛选、正文、恢复、删除或原生文件存活性扫描能力。
- [ ] 保持同机写入、局域网读取边界，不新增认证。通过公开请求分别验证允许与拒绝来源；拒绝写入不建历史，局域网仍可按既有权限读取。
- [ ] 不扫描或批量导入旧会话；预放旧对话在没有注册事件时不入历史，之后对其明确成功 register 可普通收录。此项为 P25 的本票覆盖，不重复 01 的存储策略保护或 05／06 的精确引用读取检查。
- [ ] P26 本票覆盖正常 register、元数据更新及隔离重启：保持原有 keepAlive、登记生命周期、监听和倒计时语义；重启后历史存在，当前登记及临时关机意图不恢复。复用必要的既有行为覆盖，绝不执行真实关机。
- [ ] 通过公开 HTTP 和实际浏览器验证完整 register→持久化→展示链路，更新受影响的使用说明与公开 interface 文档。分页归 03，故障反馈和恢复归 04，不以它们尚未完成代替本票正常路径证明。

## 验证边界

依据已批准 contract 的 S1、S2。独立预写 ID、字段及期望值，不能调用被测合并实现生成期望。基本唯一性与已知数据安全从本票起成立；07 拥有跨来源与并发组合验证，不允许此前明知错误仍合入。
