# 04: 安全删除 node 并更新当前 Map

**What to build:** 删除当前 Map 的 node 前检查前置依赖引用，指出阻止删除的依赖者；只有检查完整且无引用时才请求用户最终确认。确认后的生产请求重新检查安全条件，成功后留在当前 Map，清除目标选择并更新列表、详情和依赖图。

**Delivers:** P20, P27；P23, P24 的 node 部分；P31 的删除部分。

**Test owner for:** P23、P24 的 node 删除分区；P31 的删除分区。P23、P24 的模板删除分区由 05 拥有；P31 新增、修改分区由 03 拥有。各 promise 全部分区通过才完成。

**Blocked by:** 03: 当前 Map 内 node 新增、修改与即时结果展示。

**Status:** in-progress

## 验收条件

- [x] P20：B 通过 blocked_by 依赖 A 时，页面与直接生产请求均拒绝删除 A，明确指出 B；目标及依赖均未被删改。不级联删除，不自动清除依赖。
- [x] P23：仅在完整检查确认无引用后展示最终删除确认；取消保留对象及文件内容，确认才实际删除。通过生产接口重读并检查真实文件，不只验证页面提示。
- [x] P24：确认框打开后，外部或应用内操作改变目标或新增对目标的依赖时，最终请求拒绝已不安全或过期的删除。不得仅相信页面之前的检查结论；不能准确识别目标时不猜测删除。
- [x] 无法读取或校验所属 Map 时不执行删除，显示明确错误，不把检查失败视为无依赖。
- [x] 删除加入已有应用内写入协调，最终检查与实际变更受保护；提交前复查外部文件变化，不通过直接请求绕过保护。
- [x] P27：删除非被引用节点后留在当前 Map，清除被删除 node 的选择，详情消失，列表及已展示依赖图无旧节点；删除最后一个 node 后空态正确。
- [x] P31：删除只移除目标 node，其他 node 的嵌套参数、依赖及 Map 标题说明符合独立预期；其他 Map 文件不变。不要求被更新 Map 的 JSON 排版逐字节不变。
- [x] 删除失败明确显示原因且不误报成功，不进行隐式修复或执行工作。更新当前 node 删除和引用保护使用说明。

按项目规定入口执行 TDD 和真实页面验收，使用当前构建产物及网络护栏；独占临时定义、工作目录、持久化路径、进程和数值回环端口。不操作用户数据，不发起 Chat 或执行固定操作。不扩展到 Map 删除、撤销、强制删除或自动引用迁移。
