# 03: 当前 Map 内 node 新增、修改与即时结果展示

**What to build:** 在当前 Map 新增或编辑 node，使用与模板一致的独立 ID 和 JSON 内容编辑体验。保存验证完整 Map，成功后保持当前 Map、选中保存结果，并立即更新列表、详情及已展示依赖图；不要求手动刷新。

**Delivers:** P15, P16, P26；P6, P7, P8, P9, P10, P13, P14, P17, P18, P19 的 node 部分；P31 的新增、修改部分。

**Test owner for:** P6–P10、P13、P14、P17–P19 的 node 分区；P31 的新增、修改分区。模板分区由 02 拥有，P31 删除分区由 04 拥有；各 promise 全部分区通过才完成。

**Blocked by:** 02: 共享 node_template 新增、修改与返回原 node。

**Status:** in-progress

## 依据与范围

依据已批准 contract 与 spec；复用 02 已交付的编辑行为、草稿保护及应用内提交协调机制，不另建第二套。node 是 Map 内静态工作，不是执行实例；ID 仍为 nodes 对象 key，不提供独立 node 库、Map JSON 编辑、ID 重命名、跨 Map 搬移或执行能力。

## 验收条件与 coverage partition

- [x] P6：新增独立 ID 初始为空，编辑 ID 只读，JSON 内容无顶层 id；新增与修改均保存到所属 Map 并经生产接口重读。
- [x] P7：页面与直接请求拒绝顶层 id，提示移除而非覆盖；parameters 内名为 id 的合法参数可保存并重读，不误伤开放内容。
- [x] P8：新增预填现有文档中的上海出行天气 A 内容、destination-weather 引用和参数，blocked_by 为空；与独立确定的业务值核对，实际删改后保存。示例随应用提供并保持单一内容来源，部署不要求访问开发仓库文档。
- [x] P9：打开、放弃新增不持久化示例或依赖；操作前后比较隔离定义文件集合和内容，保留已有缺失配置目录初始化行为，不自动安装模板。
- [x] P10：编辑显著不同于示例的真实 node，不混入示例；保存后重读仍为真实内容。
- [x] P13：同 Map 重复 node ID 和实际并发同 ID 创建被拒绝，不覆盖原数据；不同 Map 可复用同一 node ID。
- [x] P14：页面及直接请求拒绝无效 JSON、缺失必需字段、错误类型与未知字段；所属 Map 沿用既有版本和结构规则。每类适用反例均检查具体错误及文件未被无效输入改写。合法空值沿用原规则，不给 node 添加模板才有的 implementation 规则。
- [x] P15：完整 Map 的未知前置、自依赖和环均拒绝保存；合法并行、汇合、独立节点保存后，关系与预先指定结果一致，不自动修复依赖。
- [x] P16：包含未声明参数、嵌套 JSON、未登记 zone/Bot 和不存在模板引用的合法 node 可保存；不匹配校验 inputs、不检查资源存在、不补默认值。实际页面仍明确提示缺失模板。
- [x] P17：校验错误、受控写入失败及冲突保留独立 ID 与原始 JSON 草稿，显示错误，不误报成功或离开编辑器。
- [x] P18：冲突单位为整个 Map 文件；编辑 A 期间修改同 Map 的 B，或外部编辑器在提交前修改、移除 Map 文件，旧提交失败且较新内容不被覆盖。保留草稿并提示重新加载，不自动合并其他 node 的更改。
- [x] P19：返回、切换页面、应用刷新和浏览器刷新前确认放弃已修改的 node 草稿；取消保留草稿，确认执行原动作。浏览器原生提示只验证行为。
- [x] P26：新增、修改成功后不点击刷新全部，当前 Map、选中 node、列表、详情及已展示依赖图都立即反映真实保存结果。
- [x] P31：新增及修改仅改变目标 node；独立预期验证其他 node 的嵌套参数、依赖和 Map 标题说明，其他 Map 文件原样保留。不要求更新后的 Map JSON 排版逐字节不变。

## 并发、安全与验证

node 提交必须加入与模板写入相同的应用内协调边界，保护冲突检查和真实变更，为 05 的跨 Map 引用检查提供一致提交顺序。提交前复查外部文件变化；不承诺任意外部编辑器之间的跨文件原子性。更新使用说明，提示不要在页面提交期间直接修改相关定义。

按项目测试指引执行 TDD，通过 S1 实际交付页面与 S2 页面实际调用的生产 HTTP interface 验证；完整 Map 依赖、身份空间和非目标定义保护经直接请求验证。测试预期独立于实现，用真实隔离文件，不以模拟响应替代保存；使用当前构建产物、规定 npm/后端入口和网络护栏。独占数据、工作目录、进程及数值回环端口，不发起 Chat、执行固定操作或访问用户真实定义。

本票拥有上列 node 分区和 P15、P16、P26。06 拥有 P25、P32、P33、P34 跨操作 contract 测试；本票仍必须实现安全边界并验证自身持久化。P18 的旧版本冲突不替代 06 的实际并发竞争用例。同步更新当前 node 管理说明，不改写历史 ADR。
