# 02: 共享 node_template 新增、修改与返回原 node

**What to build:** 从模板列表、空态或预览进入统一 JSON 编辑体验，以独立 ID 新增共享模板或修改其真实内容。显式保存后持久化并显示最新预览；从 node 进入的用户可返回仍存在的原 Map 与 node，看到最新共享能力。

**Delivers:** P4, P11, P12, P28, P30；P1 的空态新增部分；P6, P7, P8, P9, P10, P13, P14, P17, P18, P19 的模板部分。

**Test owner for:** P1 的空列表进入新增草稿；P6–P10、P13、P14、P17–P19 的模板分区。对应 node 分区由 03 实现并测试；P1 的导航分区由 01 拥有。各 promise 全部分区通过后才完成。

**Blocked by:** 01: 同 Tab 模板浏览、准确预览与诊断。

**Status:** ready-for-agent

## 依据与范围

遵循已批准 contract 与 spec，复用现有格式、严格校验和配置目录边界。交付真实页面到生产 HTTP interface 再到真实文件的完整路径，不建立纯存储或纯前端中间交付。复用实际需要的编辑能力，不提前建设通用编辑器框架。模板不是 Bot；本票不启动 Chat、不执行工作，不提供 ID 重命名、文件名输入或 Map 管理。

## 验收条件与 coverage partition

- [ ] P1、P6：空列表也能进入新增；独立 ID 初始为空，编辑已有模板时 ID 只读，JSON 编辑内容不含顶层 id。新增和修改都实际保存并重读；模板持久化格式仍由保存逻辑补回独立 ID。
- [ ] P7：页面及直接生产请求均拒绝内容中的顶层 id，明确提示移除，不静默覆盖独立身份。node 开放 parameters.id 的正例由 03 拥有，不放宽模板原有结构规则。
- [ ] P8：新增预填现有目的地天气能力文档示例除 id 外的完整内容，用独立确定的业务值核对。示例保持单一内容来源并随应用提供，无开发仓库文档可访问的部署环境也能打开、删改并保存草稿。
- [ ] P9：打开或放弃新增前后，隔离定义文件集合及内容不变；不自动安装模板或依赖，保留原有目录初始化行为。
- [ ] P10：已有模板仅加载真实内容；用显著不同于示例的合法对象验证没有混入示例，保存后重读。
- [ ] P11、P12：新模板自动获得安全且不覆盖现存文件的文件名；含路径语义的 ID 不成为本地路径，页面不要求文件名。已有哨兵文件保持不变；编辑文件名与 ID 不同的模板后，原文件位置及 ID 关联不变。
- [ ] P13：全局重复模板 ID 与实际并发同 ID 创建被拒绝，不覆盖已有定义；错误明确。身份歧义不允许随机选择目标更新。
- [ ] P14：通过独立反例验证 JSON 语法、版本、必需字段、类型、未知字段及未知实现类别；页面及直接请求不能绕过适用校验，无效输入不改写文件。合法空文本、空对象和空数组沿用原规则，允许删改示例条目但不删除必需结构。
- [ ] P17：校验失败、受控写入失败和冲突时保留独立 ID 与原始 JSON 草稿，显示具体错误，不显示成功或跳转成功预览。
- [ ] P18：两个客户端编辑同一模板，或外部编辑器在提交前修改、移除目标文件时，旧提交失败且不覆盖较新文件；页面保留草稿并提示重新加载。
- [ ] P19：模板草稿已修改时，返回、切换页面、应用刷新和浏览器刷新均确认放弃。取消保留草稿，确认执行原动作；原生浏览器提示仅核对行为，不断言固定文案。
- [ ] P28：新增或修改成功后无需“刷新全部”，直接显示保存结果的准确 ID 与最新业务内容。
- [ ] P4：从 node 进入模板、修改并返回，保留仍存在的原 Map 与 node 选择，呈现最新内容；来源 Map 或 node 已移除时明确失效，不显示陈旧成功数据。
- [ ] P30：同 Map 多 node 与跨 Map 引用同一模板 ID，修改后重新读取均看到新能力；检查存储不产生每 Map 副本。

## 提交与测试责任

从首次交付起，应用内写入须协调最终检查和实际变更；提交前复查外部文件变化，并保护配置目录边界。不得等 06 才补生产安全。保留直接文件维护，不承诺与不参与协调的外部编辑器之间跨文件原子性；使用说明提示避免页面提交期间直接修改相关定义。

本票拥有上列所有模板分区及 P4、P11、P12、P28、P30 的用例；03 拥有 node 分区。P18 的旧版本冲突与 06/P25 的实际竞争提交用例分开。06 统一拥有 P25、P32、P33、P34 跨操作 contract 测试，本票仍检查自身真实持久化和安全行为。

遵循项目测试指引，以 S1 实际页面和 S2 生产 HTTP 请求验证；P12 的文件位置证据经 S2 验证。使用真实隔离文件、独立预期值、规定测试入口和当前构建产物；不以模拟页面代替真实保存。测试独占工作目录、持久化路径、进程和数值回环端口，不操作真实用户数据或触发工作执行。同步更新当前模板管理说明和 scheduler 入口描述，保留历史文档事实。
