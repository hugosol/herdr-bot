# 11: 节点完成后只关闭准确关联的终端

**What to build:** 管理者确认工作完成后，自动关闭只作用于相应节点执行的目标 Tab 及其终端，允许连带关闭因此为空的容器。关闭失败保留完成事实并给出反馈。依据[合同](../contract.md)与[规格](../spec.md)。

**Test owner for:** S1 关闭目标、授权范围、确认／拒绝和失败后的完成读回；15 独占实际布局与进程验收。

**Blocked by:** 10 — Run 管理者与节点在所选宿主运行

**Repositories:** herdr-bot

**Status:** ready-for-agent

- [ ] 通过公开节点完成操作触发关闭，受控 adapter 核对选中的执行、Tab 及终端；关闭回执、移出布局和进程退出分别表示。
