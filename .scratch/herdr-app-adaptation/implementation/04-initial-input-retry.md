# 04: 明确未提交时只重试一次

**What to build:** 用户看到首条指示为何尚未提交、是否等待唯一一次重试，或者为何结果未知。只有宿主明确证明未提交，后端才对原启动目标再试一次。依据[合同](../contract.md)的 S1 与[规格](../spec.md)。

**Delivers:** P20, P24, P25, P26, P27, P28, P50, P52

**Test owner for:** 确定性拒绝、5 秒时钟、次数与取消边界、未知分类和创建副作用计数；05 拥有真实模态与终端证据。

**Blocked by:** 03 — 从 Task 发起 Chat 并提交首条指示

**Repositories:** herdr-bot

**Status:** ready-for-agent

- [ ] 发送前 blocked 不强制输入；公开响应及页面反馈未提交和等待一次重试，从明确拒绝后起算、不早于 5 秒。重复／乱序 ready 不改变起点或预算。
- [ ] 第二次仍失败保留原因并停止；观察超过到期窗口，无第三次输入。目标退出、更换会话或 owner 时取消，不发给替换目标，不创建替代 Tab／进程。
- [ ] 超时、断线、部分写入、模糊响应及 started:false 分别检查；独立记录输入可能的外部效果，不用即时历史或模型响应缺失推断未提交，不自动重投。
- [ ] 受控时钟和故障经公开操作验证页面状态及外部计数；只重试初始提交，创建只有一次。恢复及报告通知分别由 07、09、10 拥有，不扩展重试策略。
