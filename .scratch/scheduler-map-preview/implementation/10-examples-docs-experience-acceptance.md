# 10: 可复制样例、说明与体验验收

**What to build:** 用户或未来定义生成者可按准确说明准备独立 Map 与共享模板样例，经同一真实入口核对计划；全部自动工作完成后，用户可基于可运行页面与完整材料确认桌面和窄屏的主观体验。

**Delivers:** P31, P32, P33。

**Blocked by:** 08 — 读取边界与只读安全闭环；09 — 图形交互、键盘与窄屏可操作性。

**Status:** in-progress

## Acceptance criteria

- [x] 按 spec 已批准的交付位置提供独立 Map、共享模板样例及格式说明，样例遵守相同受支持格式，不把模板副本嵌入 Map，也不创建另一种专供图形展示的数据格式。
- [x] 交付样例覆盖同模板不同参数、跨 Map 模板复用、并行、汇合与独立节点；文档明确这些是人工示例能力，不表示已实现执行。
- [x] 使用交付样例本身，按说明复制到隔离配置目录，在 S1 逐项验证事先确定的节点、关系、参数与模板说明；样例不随首次启动自动混入用户数据。
- [x] 格式说明准确覆盖版本、必需字段、snake_case、Map 内 node ID、blocked_by 方向、模板 id 身份、开放 parameters、命名输入输出说明及 chat 类型；说明严格结构校验与模板问题行为，不增加参数契约校验或执行配置。
- [x] 更新当前领域词汇与使用说明，准确区分 Map、node、共享 node_template、Bot、Chat 与执行实例；Map 与 node 是静态定义，不是运行状态，模板不是 Bot，依赖边不是执行路由或材料传递。不改写历史 ADR。
- [x] 使用说明与实际配置、默认目录、cwd 相对路径解析、自动创建且保留已有文件、列表刷新、重新加载、目录及模板错误、server 新入口一致；按说明实际操作核验，不只审阅文字。
- [x] 前序票随行为更新的说明在此统一核对，不让文档滞后被解释为前序票可不更新说明；不新增文档专用运行 seam。
- [x] 在人工体验轮开始前完成全部已分配自动检查，按项目交付入口执行应有回归与构建后真实浏览器验收；不因 P33 待人工而暂停其余可执行工作。
- [x] 为 P33 准备可运行页面、覆盖并行／汇合／独立节点的样例、桌面与窄屏截图、操作说明及已知限制，实际检查图布局、文本可读性和 node／模板明细层次。
- [x] 最终交接明确列出自动验证结果及仍待用户确认的 P33；用户确认前 P33 保持未验证，不将截图准备完毕表述为体验验收通过。
- [ ] 依据用户体验反馈完成必要修正并重新验证受影响行为，取得用户确认后才将 P33 视为完成；若有真实阻塞，记录缺失前提与已尝试事项，不伪造通过。
