# 07: 当前文件重载与迟到结果隔离

**What to build:** 用户修改服务端 Map 或共享模板后，通过显式刷新或重新加载看到当前内容，无需重启；快速切换文件时，较早请求的迟到结果不能覆盖当前选择及其图、详情。

**Delivers:** P25, P26。

**Blocked by:** 04 — 共享模板关联与按需明细。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 提供显式刷新列表及重新加载操作，读取当前 Map 与共享模板内容；不引入自动文件监听、模板快照或版本锁定。
- [ ] 在同一个真实服务进程中修改依赖与参数、共享模板文本，操作后逐项对照事先独立写定的新预期，不残留旧边、旧 node 信息或旧模板说明。
- [ ] 新增与移除 Map 文件后刷新列表，列表反映当前文件集合；不要求重启服务或访问设备提供本地文件。
- [ ] 受控延迟 A 的真实响应，选择 B 后再释放 A；页面仍属于 B，当前选择、图、node 详情和已展开模板说明均不能被 A 覆盖。
- [ ] 覆盖较早选择或重新加载请求迟到的归属场景；延迟只改变时序，不替换业务内容，不依靠任意睡眠制造期望结果，不新增重试、超时或事务一致性产品承诺。
- [ ] 使用实际文件与真实页面通信验证 S1；通过项目 npm 入口运行浏览器检查，按测试指引判断时序检查是否需要既有时间契约分区标记。
- [ ] 浏览与重载不写 Map／模板，不启动 Chat、不执行脚本、不按参数读取路径；08 接续完整安全验收。
- [ ] 同步更新刷新与重载说明，明确外部写入期间读到不完整 JSON 可按错误显示，写完后再重载；不声称已提供跨文件原子快照。

## Contract coverage

本票拥有 P25、P26 的完整实现与测试。Map 失败清场与恢复由 05 负责，模板局部问题由 06 负责；这些票不构成本票合法内容重载和迟到结果检查的启动前提。
