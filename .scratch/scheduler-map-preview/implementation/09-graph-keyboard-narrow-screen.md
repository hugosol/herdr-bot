# 09: 图形交互、键盘与窄屏可操作性

**What to build:** 用户可通过图的布局和视图控制核对计划，使用键盘进入 node 明细，并在窄屏访问文件列表、图、node 详情与模板明细，而不需要依赖桌面宽度或仅鼠标操作。

**Delivers:** P12, P30；P4 的 node 选择与明细入口覆盖。

**Test owner for:** P4 的 node 选择与明细入口键盘操作；01 负责 scheduler 与 server 导航覆盖，双方通过后 P4 才整体完成。

**Blocked by:** 04 — 共享模板关联与按需明细。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 依赖图自动布局；包含并行、汇合及独立节点的真实输入无需手工安排节点位置即可查看，不固定具体布局算法或精确坐标。
- [ ] 使用真实鼠标、触控等实际支持的交互验证平移、缩放及适应画布，观察视图变化，并确认适应画布后各节点可查看；不能只调用内部视图函数。
- [ ] 使用真实键盘完成 node 聚焦、选择及明细入口激活，能核对当前 node 信息；与既有 scheduler 导航配合，不用脚本直接触发处理函数代替键盘证据。
- [ ] 在真实窄屏 viewport 中完成选择 Map、查看图、选择 node、展开模板及返回相应内容；必要控件可触达，不依赖桌面隐藏区或不可操作的横向裁切。
- [ ] 准备桌面及窄屏的图形交互截图，覆盖并行、汇合与独立节点；只断言自动可操作性，不把主观美观和可读性视为自动通过。
- [ ] 经 S1 的真实页面与文件验证，沿用项目浏览器入口、构建和安全隔离约定，不引入另一套测试框架。
- [ ] 同步更新图形控制、键盘和窄屏操作说明；10 负责完整 P33 人工体验验收，用户确认前不得提前宣称 P33 通过。

## Contract coverage

P4 中 node 选择与明细入口的测试仅由本票负责，导航入口测试仅由 01 负责。P12、P30 的完整自动覆盖归本票；本票提供的截图可供 10 使用，但不单独认领 P33 完成。
