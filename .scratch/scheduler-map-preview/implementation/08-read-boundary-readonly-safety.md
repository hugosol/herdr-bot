# 08: 读取边界与只读安全闭环

**What to build:** 用户可安全浏览、展开和重新加载定义：业务文本只用于展示，生产读取不能越出配置目录，操作不修改定义或启动任何工作。完成正常、错误及重载路径的跨入口安全验证，并修复发现的问题。

**Delivers:** P18, P27, P28。

**Blocked by:** 05 — 无效 Map 的拒绝、清场与恢复；06 — 模板问题提示与故障隔离；07 — 当前文件重载与迟到结果隔离。

**Status:** in-progress

## Acceptance criteria

- [x] 通过真实浏览器展示包含 HTML 标记、脚本样式和指令样式内容的 Map、node、模板业务文本与参数；文本不被当作 HTML 或代码执行，无受控副作用记录。
- [x] parameters 包含目录外受控文件路径时，仅按 JSON 值展示，不返回目标文件预置内容、不把参数解释为读取或执行指令。
- [x] 直接向主界面实际使用的生产 S2 提交越界请求，并提供指向目录外受控文件的链接反例，验证明确拒绝且不泄露内容；正常目录内文件作成功对照。
- [x] Map 与共享模板读取入口均遵守各自配置边界；不能只检查 UI 不提供越界按钮，也不能新增测试专用读取 interface 代替生产路径。
- [x] 对浏览列表、选择 Map、查看 node、展开模板、错误后恢复及显式重载，比较真实预置 Map／模板文件操作前后的内容，确认没有修改、清空、修复或覆盖。
- [x] 使用既有受控执行替身，验证上述操作没有新增 Chat 启动、脚本或危险操作调用；不能只用页面没有执行按钮证明无执行。
- [x] 目录及必要父目录自动创建作为唯一获准的文件系统写入单独验证，既有文件保留；示例不会自动安装到用户数据。
- [x] 证据同时覆盖 S1 与实际 S2；全部反例使用隔离真实文件与进程、数值回环地址及现有 npm 网络护栏，不读取用户真实数据或调用外部能力。
- [x] 更新只读、安全展示与读取范围说明；不擅自加入文件大小、数量或图规模配额，如确需限制，先请求修订合同。
