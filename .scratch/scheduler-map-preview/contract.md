## Seam decisions

|Seam|Exposes|Hides|Alternatives considered|Reversibility|
|---|---|---|---|---|
|S1 — 真实主界面 interface|文件选择与重新加载、导航、图与明细、错误提示、桌面/窄屏及键盘操作；真实配置与文件变化在用户入口的结果。|图形库、布局算法、解析与索引组织、缓存和内部调用；不固定坐标、私有模块或测试专用 interface。|批准复用现有真实浏览器入口。拒绝以纯 mock 展示作为完成证据，因为不能证明文件读取和更新。拒绝每个内部模块分别成为合同 seam，因为会锁定实现结构。|内部 implementation 可替换，只要 promises 继续成立；用户交互承诺发生改变须先修订合同。|
|S2 — 主界面实际使用的文件读取 HTTP interface|生产只读操作的成功与失败结果，以及直接请求的目录读取限制；真实配置与文件输入，不仅是页面按钮提供的路径。|文件读取器、模板索引、依赖检查器及其内部 seams；本合同不锁定具体路由名或传输字段。|批准在既有 HTTP 交互方式上扩展必要只读操作。拒绝仅 S1 验证，因为隐藏越界按钮不能证明伪造请求被拒绝；拒绝专设测试读取 interface。|路由和内部实现尚未锁定；更改时保持同一个生产 interface 的消费者与检查一致，安全和错误承诺不能退化。|

### 已批准的约束选择

- 模板重复身份：报该 id 冲突，保留图并隔离正常模板；拒绝按扫描顺序任选，因为同一引用会得到不确定说明。
- 定义结构：严格检查必需 key、类型、未知结构字段及版本；业务 parameters 保持开放。拒绝漏填后静默默认化，因为拼错依赖可能被误画成独立工作。
- 目录准备：默认位置无需手动配置；不存在时自动创建含父目录，保留既有文件。最初“不自动创建”的建议被用户否决，因为增加首次使用负担；不得将它作为后续实施依据。
- 创建目录不扩大为写定义：不自动修复 Map、覆盖模板或安装示例。示例按文档手动复制的既有范围不变。
- 验收分工：选择 Rapid iteration 而非 Full automation，仅将 P33 主观体验留给用户；自动功能、真实浏览器及安全检查不豁免。

### 依赖与证据约束

- In-process：解析、图关系计算和界面状态等留在 implementation 内，不为它们新增外部 seam。
- Local-substitutable：文件系统使用测试拥有的真实临时目录，既有危险操作使用既有安全替身。证据必须能区别真实读取失败和人为返回空数据。
- 本轮没有需要新接入的 True external 能力；天气、Codex 与 LLM 不参与运行验收。浏览器与现有后端之间的真实通信整体进入观察，不因传输存在就新增测试端口或替代生产 interface。
- 沿用 spec 的隔离、安全、构建及网络护栏约束。不得操作用户真实 Chat、执行真实关机或用真实外部能力弥补示例数据。

### Material trade-off

严格结构格式优先发现拼写错误而非静默前向兼容。以后增加结构字段或实现类型时，旧读取方可能拒绝新格式，需要有意识更新格式支持与相关文件；影响生成方、读取方与说明文档。用户已确认该选择；保留严格检查，不在实现中默默放宽。此处不额外建立独立 ADR：本阶段格式仍可有意识演进，尚未证明达到难以逆转的门槛。

## Not yet specified

- **非阻塞、留给 implementation**：图形库、布局算法、内部模块组织、具体 HTTP 命名、错误文案和视觉样式；不得改变本合同的可观察结果。P33 用于确认视觉体验，不预先固定像素。
- **延后且不构成本轮承诺**：任意规模图的性能目标、跨文件原子快照及外部写入期间的事务一致性。读取到尚未写完的 JSON 时按错误显示，写完后可重新加载。
- **资源限制尚无获准阈值**：不承诺无界处理；若实施发现必须以文件大小、文件数量或图规模拒绝输入，应提出明确限制并先补充合同，不能静默截断或擅自指定产品配额。
- **没有阻塞批准的未决选择**。若实现证据推翻 seam 或 promise，先修订合同，再重新打开受影响 tickets，不默默偏离。
