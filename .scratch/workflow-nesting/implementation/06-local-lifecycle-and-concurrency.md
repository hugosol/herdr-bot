**What to build:** 父子 Run 保持独立控制边界；暂停、失败和并发交接不会隐式级联或因父子互等无法推进。

**Blocked by:** 05: 完成子流程交付与父层显式验收

**Repositories:** herdr-bot

## Acceptance criteria

- [ ] 父暂停后本层新 dispatch／retry 被拒绝，但已启动 child 及内部工作继续；恢复资格不自动派发。
- [ ] 子内部失败不自动失败、暂停、终止祖先或独立分支；同时核对公开状态及受控会话效果。
- [ ] 交错父 dispatch、子 report／finish、父 complete，并同时运行独立 Run；以受控门闩和有界结果证明能推进，不能只用不抛错断言。
- [ ] 慢宿主效果或通知不应形成父锁等子、子锁等父的互等；只约束可观察推进，不固定锁数或私有实现。
- [ ] 失败分支释放门闩并等待所属已接受任务，保留原始与清理错误，不增加自动恢复、级联或规模性能承诺。
- [ ] 所有受影响调用方与既有行为检查同步切换，删除被本次替代的死路径，不引入旧字段别名或以兜底吞掉失败。
- [ ] 更新所属长期使用／运行／验证说明，记录真实执行的入口及证据边界；临时 ticket／证据不作为长期文档唯一依赖。
