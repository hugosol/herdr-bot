- [ ] outline 通过新 report 声明 can_complete 并登记命名概要方案输出；generate_map 声明对应来源输入，直接使用解析地址。删除筛选报告、按时间／目录猜最新文件和重复机械身份交接协议。
- [ ] 保留独立概要方案、方案标识／修订、确认范围、稳定工作编号、真实 Bot／Task 绑定、业务输入输出、zone、权限及未决事项。九章节以既有 Task 约定为准，不退化成早期四标题草案。
