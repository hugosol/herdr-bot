# Ticket 07 TDD 执行复盘

## 1. 高：把真实验收前提设为调度就绪门槛

**事实**：票据要求 OMP/Pi 使用 GPT-6-luna 完成真实启动与恢复。Main 明确回复本轮没有独立 paths、模型配置或授权 key。执行代理检查了现有真实传输设施，确认它们同样需要显式授权输入；最终真实入口因缺少模型配置返回非零，未发起真实模型请求。P7 因而没有闭合，不能由六个受控 chief dock 用例替代。

**建议**：由调度器在派发这类真实验收票之前检查“验收依赖清单”：授权配置的安全定位符、已授权凭据入口、宿主及官方状态扩展位置、构建产物定位。只检查可用性与访问权限，输出脱敏缺项，不读取或保存凭据正文。缺项时保持票据阻塞；“代码依赖已合并”与“真实验收前提已满足”分别登记。

**预期收益**：避免完成大量实现与回归后，才把整票停在一开始已知缺失的真实依赖上，同时保留本轮正确的 fail-closed 边界。

## 2. 高：为重型验证提供统一资源租约

**事实**：代理分别联系两个集成代理协调重型窗口；一个代理曾持有窗口，另一个也在运行完整浏览器与后端检查。Ticket 07 随后等待释放，并多次调用 `wait`；宿主提示“等待不是进展”。之后获得明确释放才开始重型检查。

**推断**：点对点协调无法可靠表达整台机器的占用状态，也是“继续推进”与“保持验证窗口安静”两条指令发生冲突的原因之一。现有记录不足以把其他代理报告的超时直接归因于资源争用。

**建议**：由宿主维护一个跨 worktree 的重型验证租约，统一排队并自动通知获得者；租约声明构建、浏览器、原生 dock 等资源类别。代理等待租约时应进入可恢复的阻塞状态，而不是靠重复询问或 `wait` 保持执行。把排队与释放交给宿主，不再增加代理需要记忆的协调规则。

## 3. 中高：将原生 artifact 准备移出五秒测试 hook

**事实**：首次 toolkit canonical 检查出现 `viewed-marker.test.ts` 未命名 hook 超时，耗时约 5000.35ms，并报告终止一个 dangling process。源码中的 `beforeAll` 调用了 `ensureViewedSessionHarness`，未显式设置较长预算；检查时可见 staging 目录和已生成的最终 artifact。随后串行 dock 为 181 通过、6 跳过，之后 canonical 为 1848 通过、6 跳过、0 失败；首次失败日志被保留。

**推断**：冷 artifact 的物化超过默认 hook 预算，是与记录相符的解释，但本轮没有独立故障注入证明这一因果关系。

**建议**：在 canonical 入口之前增加显式、可记录的 artifact 准备阶段，完成条件为来源身份核对、物化完成、发布资格释放及就绪记录可读。测试 hook 只消费已就绪 artifact，缺失时给出具名前提错误。沿用现有串行预热设施，而不是放宽业务断言或隐藏原始超时。

## 4. 中：限制图索引与工具输出的无效上下文成本

**事实**：fast 索引明确排除了 `scripts` 等目录，但代理仍对这些已知排除目录请求声明大纲，得到空结果。早期 `find` 的所有判断请求因 451 失败。浏览器分区检查成功，却输出了完整清单：约 8929 行，工具显示大量内容被截断。

**建议**：

- MCP 在返回空结果时区分“没有声明”与“路径未覆盖”，并附带可执行的读取路径建议。客户端使用已有覆盖信息跳过必然为空的大纲请求。
- `find` 对统一鉴权或地域错误尽早终止候选判断，并明确推荐可用的替代工具。
- 为现有浏览器分区检查增加摘要输出模式；默认打印集合计数、差集与清单文件位置，失败时才展开差异。原始清单仍保存，但不进入常规上下文。

这些属于工具与检查入口的确定性改进，不需要新增编码标准。

## 5. 中：保留本轮的行为 red，避免把 CLI 缺失当作充分 TDD 证据

**事实**：最初 CLI 测试的 red 来自入口文件不存在、证据文件不存在以及缺少绝对路径错误提示。这只能建立接口缺失，不能单独证明业务断言敏感。之后新增的公开后端测试实际运行，因交付元数据缺少 `omp-chief-chat` 失败；补齐两宿主固定声明和 chief-only 适用映射后，同一测试通过，并覆盖 normal/manager 排除及无 Suite 启动、恢复。

**建议**：在现有 TDD 结果报告中分开标注“接口 red”和“行为 red”。对本轮这样的缺失接口，继续要求接口接通后取得一个触及真实违规条件的失败或既有覆盖证据。复用现有 TDD 指导即可；无需再向 AGENTS.md 复制规则，也不必强迫已经满足的生命周期行为制造失败。
